## 二、每个项目的开源包结构（统一规范）

```
{repo-name}/                     例：student-course-selection-springboot
├─ README.md                     中文，含引流区（置顶 + 结尾各一处站点链接）
├─ LICENSE                       许可与来源声明（学习使用，不含商业授权）
├─ docs/
│   ├─ screenshot-1..n.png       演示截图（脱敏后）
│   └─ demo.mp4                  演示视频（可选，放外部链接也行）
├─ db/
│   └─ xxx.sql                   建表 + 示例数据（脱敏）
└─ src/…                         精简版源码（完整框架 + 核心 1-2 模块）
```

### README 结构（固定）
1. 项目名 + 一句话简介
2. **👉 完整项目 / 演示录屏 / 更多项目：{自建站地址}**（置顶）
3. ✨ 功能清单（前台 / 后台分组）
4. 🛠 技术栈（含版本）
5. 📁 目录结构
6. 🚀 快速开始（环境要求 + 命令 + 端口 + 默认账号）
7. 📸 截图
8. ❓ 常见问题（跑不起来 / 端口占用 / 数据库连接）
9. **开源版包含什么 / 不包含什么**（如实说明）
10. 免责声明 + 来源与许可
11. 结尾再放一次：**更多完整项目 → {自建站地址}**

## 三、开源版"精简"的正确做法（不随机删文件）

**保留**：完整工程框架（pom/配置/启动类）、用户登录与权限、**1-2 个核心业务模块**、数据库脚本（含少量示例数据）、运行说明
**移除**：其余业务模块（保留接口占位或直接删除并同步清理引用）、论文/PPT/开题报告、私人信息、第三方品牌内容
**必须**：移除后要**能编译、能启动、能演示核心功能**；README 写清"开源版含 X 模块，完整版含 Y 模块"
