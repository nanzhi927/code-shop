## 一、先把"谁会买、为什么买"想清楚

| 人群 | 阶段 | 痛点 | 决策关键 |
|---|---|---|---|
| 大四计算机/软件/信管学生 | 9-12月选题 | 不知道做什么、怕选题太大做不完 | 有现成选题清单、能跑的源码 |

| 同上 | 3-5月做毕设 | 不会写代码、跑不起来、没时间 | **能跑通 + 有人教 + 便宜** |

| 二次购买/同学推荐 | 全年 | 相信熟人 | 转介绍返现 |

**结论：成交高峰在 3-5 月；现在到年底是"攒粉+加微信+建群"的黄金期，别指望现在大量成交。**

## 三、转化漏斗（每一环都要顺）

```
内容曝光（小红书/B站/抖音/知乎/QQ群）
   ↓  主页简介 / 评论区置顶 / 群签名
自建站商品页（http://62.234.122.127:40621/products/{id}）
   ↓  悬浮"联系客服"按钮 / 联系我们页 → 显示微信二维码
加客服微信/QQ（私域，关键节点！）
   ↓  发商品链接 + 报价 + 演示视频
付款（支付宝/微信收款码 → 我已完成付款）
   ↓
网盘发货（订单号核对）
   ↓
售后答疑 / 远程协助（增值收费）
   ↓
好评截图 → 转介绍返现 → 同学团购
```

**漏斗优化点（你现在就能做）：**
1. 客服微信二维码放到悬浮弹窗 + 联系我们页（已支持，记得在后台上传**微信个人二维码**而不只是收款码）
2. 商品页挂**演示视频**（video_url 回填）→ 减少"问了不买"
3. 加"**3 分钟能不能跑起来**"的保证话术（差异化）
4. 私域欢迎语自动回复：发"选题清单"+ 商品目录

2. **校园代理**：每校 1-2 人，成交分成 20-30%，给专属优惠码（可追溯）

4. **老客户二次购买**：8 折 + 优先发货
5. **售后评价截图**：收集授权后作为内容素材（真实感强）

**每周复盘**：哪个渠道加的微信最多、转化最高 → 下周加倍。

## 九、合规红线（别踩）

1. 不承诺"包过""代写论文""保毕业"——平台违规 + 学术风险
2. 公开内容/仓库**必须脱敏**（学校、学号、姓名、论文正文）
3. 闲鱼虚拟商品按其规则发布，不写违禁词

5. 源码交付声明"仅供学习参考"，避免版权纠纷
