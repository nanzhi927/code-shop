## 二、各平台上传模板

### 1. 微博（图文/九宫格）
- 标题（首行）：`毕设源码｜{项目名}｜{技术栈} 完整可运行✅`
- 正文模板：
```
🔥 毕设还在纠结选题？这套《{项目名}》拿去直接用！
✅ 技术栈：{SpringBoot/SSM/JSP...}　✅ 含数据库脚本+论文+PPT
✅ 已实测可运行，导入即跑
👉 完整演示与文件清单：{自建站商品短链}
#毕业设计 #计算机毕业设计 #毕设选题 #源码分享 #{技术栈}源码
```
- 配图：首页截图 + 登录页截图 + 运行截图（九宫格前 3 张放演示图）
- 频率：每天 2-3 条，错峰 11:00/17:00/21:00

### 2. 小红书（种草笔记）
- 封面：大字标题图（如"2026 毕设选题｜{项目名}，一键跑通"），尺寸 3:4
- 标题公式：`毕设救星｜{项目名}完整源码，{技术栈}，导入就能跑`
- 正文模板：
```
姐妹们/兄弟们，毕设选题别头秃了！
今天分享《{项目名}》完整源码 🎓
✨ 技术栈：{...}　✨ 功能：{3-5 个功能点}
✨ 含：源码+数据库脚本+论文+运行截图
📌 已实测可运行，有演示视频
评论区扣 1 或主页看详情 ➡️ {自建站链接（小红书外链受限，放主页/私信引导）}
#毕设 #计算机毕设 #毕业设计选题 #Java毕设 #{技术栈}
```
- 注意：小红书外链会限流，引流话术用"主页简介/私信/评论区"承接；简介写自建站域名
- 频率：每天 1-2 篇，同一项目换封面可发 2-3 次

### 3. B站（讲解视频）
- 视频：用 v3 真机讲解视频（3-5 分钟）
- 标题：`【毕设源码】{项目名}｜{技术栈}｜完整演示+运行教程`
- 简介模板：
```
📌 项目：{项目名}
🛠 技术栈：{...}
✅ 功能：{...}
🔗 源码与文档：{自建站商品链接}
⏱ 时间轴：00:00 项目介绍 00:30 前台演示 01:40 后台演示 02:50 运行方法
🎓 需要其他毕设源码可在评论区留言或私信
```
- 分区：科技 → 编程；加 3-5 个相关标签；封面统一模板（项目名+截图+"毕设源码"角标）
- 频率：每周 3-5 条（量大有优势）

### 4. 抖音（短视频）
- 视频：截取 v3 讲解中最炫的 15-40s 片段（运行效果+关键功能），加字幕
- 文案：`{项目名}｜{技术栈}毕设源码，演示+讲解，主页有更多 🎓 #毕业设计 #毕设源码 #编程 #java`
- 引流：主页简介放自建站域名；评论区置顶"完整版见简介"
- 频率：每天 1-2 条

### 5. 闲鱼（虚拟商品）
- 标题：`{项目名} 毕设源码 {技术栈} 含数据库/论文/运行教程 可远程`
- 描述模板：
```
✅ 商品：{项目名} 完整源码（{技术栈}）
✅ 包含：项目源码 + 数据库脚本 + 论文/PPT（如有）+ 运行必读
✅ 服务：付款后网盘发货；可提供运行指导/远程协助
📌 购买前请先看详情/聊一聊确认需求
⚠️ 虚拟商品发货后概不退换（可先看演示视频：{自建站链接}）
```
- 注意：闲鱼虚拟商品规则——不要直接卖"论文代写"；描述避免"包过/代做"违规词；引导到自建站看演示
- 价格：与自建站一致或略高（留出平台抽成）

### 6. Gitee（国内代码展示+互引）
- 仓库结构（每项目一个仓库或按技术栈一个仓库+分支）：
  - `README.md`（模板见第三节）
  - `docs/截图/`、`数据库脚本/`、`源码/`（或按项目原结构）
- 仓库名：`{项目名}-{技术栈}`；描述：`{项目名} 毕设源码（{技术栈}），完整可运行，演示视频见 https://{自建站域名}`
- Gitee 挂件：README 顶部放 自建站 徽章链接；Gitee 首页/个人主页填自建站网址

### 7. GitHub（国际代码展示）
- 同上结构；README 用中英双语开头（英文关键词利于海外搜索）
- 仓库 Topics 打标签：`graduation-project` `springboot` `ssm` `javaweb`
- GitHub 个人主页（profile README）放自建站链接

### 8. 自建站（成交页，已具备）
- 每商品页已含：详情（功能/技术点/表结构）、截图、运行环境、质检状态、价格、购买流程、客服
- 补充建议：每商品页加"演示视频"（video_url 回填讲解视频）+ Gitee/GitHub 仓库链接（互引闭环）

### 9. 知乎（建议加）
- 回答模板：`毕业设计选题推荐/Java毕设做什么？` → 列 5-10 个项目名+一句话亮点+`完整项目见 {自建站}`；专栏发《{技术栈}毕设源码合集（持续更新）》
- 注意：知乎外链管控严，正文放链接易被限流，用"个人简介+评论置顶"承接

### 10. CSDN/掘金（建议加）
- 文章：《{项目名}：基于{技术栈}的{系统}设计与实现（含源码+数据库）》
- 结构：项目背景→技术栈→功能模块→数据库设计→运行步骤→演示截图→`源码获取见 {自建站}`（文末）

## 三、Gitee/GitHub ↔ 自建站 互相引流方案（核心）

**Gitee/GitHub README 模板（放每个仓库顶部）：**
```markdown
# {项目名}（{技术栈}）

> 🎓 毕业设计源码 · 完整可运行 · 含数据库脚本与运行文档

## 演示视频与文件清单
👉 [在线演示 / 讲解视频 / 完整文件清单](https://{自建站域名}/products/{商品id})

## 功能模块
- ...

## 技术栈
- 后端：...
- 前端：...
- 数据库：MySQL（脚本见 db/ 目录）

## 快速运行
1. 导入数据库脚本
2. 修改配置（数据库账号/端口）
3. 启动项目，访问 http://localhost:端口

## 截图
![首页](docs/screenshot-1.png) ...

---
⭐ 如果对你有帮助，欢迎 Star；更多毕设源码见 [源码商城](https://{自建站域名})
```

**互引闭环：**
1. 代码平台 → 站：README 徽章/链接 + 描述带站域名 + 评论置顶
2. 站 → 代码平台：商品详情页"开源示例"区放 Gitee/GitHub 仓库链接（增强信任+SEO 外链）；站内"开源项目"页聚合所有仓库
3. 数据打通：所有站外链接带 `?utm_source=gitee/github/weibo...`，后台看引流来源（可用现有 search_logs 扩展或简单统计）
4. 更新同步：新项目先发 Gitee/GitHub（仓库+README）→ 再发各内容平台 → 全部指向自建站商品页

## 四、合规与风险提醒（重要）

1. **版权/学术风险**：毕设源码常含学校、学号、作者、论文等个人信息——**公开上传前必须脱敏**（删个人信息、论文只给目录/摘要、水印）。
2. **GitHub/Gitee 公开仓库**：不建议把全部 1529 个直接公开（会被白嫖+版权风险）。建议：挑 30-50 个做"开源引流款"（README 完整、可运行），其余在自建站出售；或仓库设私有，README 用图片展示（看不到源码）。
3. **闲鱼规则**：虚拟商品需符合平台类目，避免"代做/包过"等词；引导至自建站成交更安全。
4. **外链限流**：小红书/知乎外链受限，用"主页简介/私信/置顶评论"承接。
5. **平台去重**：同一项目多平台发布内容不要完全一样（改标题/封面/首图），防平台判定搬运。
