# 前台「高级感」全面解决方案

> 目标：把「功能齐全的源码商城」做成「有品牌感的精选商店」。  
> 原则：克制、字阶、真视觉、少组件脸、少促销噪点。  
> 受众：即将毕业 / 课程实训学生（信任感 + 专业感，而不是廉价促销感）。

---

## 0. 问题诊断（为何现在不高级）

| 维度 | 现状 | 高级站通常怎样 |
|------|------|----------------|
| 字体 | 系统默认（雅黑/Arial） | 有辨识度的展示字 + 正文对 |
| 首屏 | 角标+标题+副文+搜索+四数据 | 品牌 + 一句标题 + 一句说明 + 一组 CTA |
| 视觉 | 抽象光斑渐变 | 产品/场景真实图或精致静帧 |
| 组件 | Element Plus 默认脸重 | 自研按钮/芯片/卡片，组件库只做表单底盘 |
| 信息密度 | 领券条、芯片墙、多区块抢视线 | 一屏一任务，留白是设计的一部分 |
| 细节 | emoji、大红价、SaaS 竖条标题 | 无 emoji、价格克制、标题靠字重不靠装饰条 |
| 动效 | 杂或几乎无品牌感 | 2～3 个有意图的入场/悬停 |

结论：**配色（墨黑青绿）已及格；高级感差在字体、首屏构图、视觉锚点、组件定制与信息克制。**

---

## 1. 设计方向（定调，避免再漂）

### 1.1 一句话定位
**「墨色纸张上的精选源码店」**  
安静、可信、偏编辑型电商（参考：精品独立站 / Mobbin 级留白），不是券商城，不是管理后台皮肤。

### 1.2 硬约束（与站点规范对齐）
- 首屏一个构图，不做仪表盘
- 品牌名在首屏是英雄级信号（可与主标题并列，但不能被数据条压过）
- 禁止：紫靛渐变脸、暖奶油衬线土味、报纸密排
- 禁止：首屏堆统计、券、日程、多段营销
- 卡片默认少用；Hero 禁止卡片；仅交互容器才用卡片壳
- 主视觉优先真图，不用抽象渐变冒充

### 1.3 色与材质（在现有 token 上「收」而不是「换皮」）

保留：`--ink`、`--accent`（青绿只做点缀，不作大面积品牌主色）

调整建议：

| Token | 建议 | 原因 |
|-------|------|------|
| `--bg` | 略更冷的纸白 `#f6f6f4` 或纯净 `#fafafa` | 减少「灰脏」 |
| `--price` | 改墨色或深红褐 `#9f1239`，降饱和 | 少「淘宝红」 |
| `--accent` | 仅用于：链接、选中下划线、极小指示 | 大面积用墨 |
| 阴影 | 更薄、更贴边（hairline + 一层软阴影） | 高级站阴影几乎看不见 |
| 圆角 | 统一 8 / 12，少用 999 pill（除搜索/主 CTA） | pill 过多显模板 |

### 1.4 字体方案（最高 ROI）

| 用途 | 推荐（可商用需核对许可证） | 用途说明 |
|------|---------------------------|----------|
| 中文展示 | **霞鹜文楷 / 思源宋横** 二选一作标题，或 **阿里巴巴普惠体 3.0** 粗号 | 有辨识度，避免雅黑 |
| 中文正文 | **思源黑体 / Noto Sans SC** | 屏显清晰 |
| 英文/数字 | **Geist / Satoshi / Instrument Sans** | 价格、编号、英文更「产品」 |

落地：`index.html` 引入（或自托管 woff2）→ `global.css` 设 `--font-display` / `--font-body`。  
标题用 display，正文/UI 用 body；**禁止整站一种系统字体。**

### 1.5 字阶（建议）

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 40–56 | 600–700 | 仅 Hero 主标题 |
| H2 | 22–28 | 600 | 区块标题（去掉左侧竖条） |
| H3 | 16–18 | 600 | 卡片标题 |
| Body | 14–15 | 400 | 正文 |
| Meta | 12–13 | 400–500 | 标签、销量（无 emoji） |

字距：大标题 `letter-spacing: -0.02em～-0.04em`。

## 2. 信息架构与页面改造

### 2.1 首页（第一优先级）

**现在 → 目标**

| 区块 | 处置 |
|------|------|
| Hero 四数据 | **移出首屏**，改为页中一条细「信赖条」或删除 |
| 领券条 | 默认隐藏或收到个人中心；首屏不出现 |
| 抽象光斑 | 改为 **全宽主视觉**：精选项目界面拼贴 / 单张高质量截图全bleed |
| 分类 chips | 保留，但改成横滑编辑条，去掉厚卡片阴影 |
| 技术栈宫格 | 改为 **文字链接行** 或 2 列极简行，不要色块卡 |
| 热销 / 最新 | 保留双列精致商品卡；排序控件自制，不用 Element radio-button 脸 |
| 流程 steps | 保留一节，图标改线性/单色，去掉 emoji |

**首屏唯一构图（建议文案骨架）**

```
[品牌字标] 源码商城
主标题：精选可运行的实训项目
副文：按技术栈挑选，对照演示，独立完成你的部分
CTA：浏览全部 ｜ 按 SpringBoot 看
（背景：真实项目界面大图，暗色遮罩保证字可读）
```

搜索：**不要做成 Hero 里的大输入框**（那是工具站脸）。放到顶栏即可；Hero 用两个文字按钮。

### 2.2 顶栏 / 页脚

- Logo：字标为主（「源码商城」），方块「码」缩小或改为细线图腾
- 搜索 pill 保留，但更矮、更 quietly
- 底栏 Tab（移动端）保留，选中态用墨色+细顶线，少青绿大块
- 页脚：深墨底 + 稀疏链接（合集 / Gitee / 联系），去掉口号堆叠

### 2.3 列表页

- 筛选：左侧或顶部 **文字+细线**，激活态墨底白字，不要紫色/厚阴影 chip
- 结果区：2～3 列，封面 4:3 或 16:10，标题两行截断，技术标签胶囊极淡
- 分页：居中，弱化 Element 默认蓝

### 2.4 详情页

- 左图右信息；价格用展示字体、墨色主价，划线价灰色
- 购买条：一主一辅（立即购买 / 加入清单），少四个平权按钮
- 吸底栏：保留，但去掉 emoji，与移动底栏对齐安全区
- 「材料清单 / 演示路径」用编辑排版，像说明书不是后台表

### 2.5 购物车 / 结算 / 登录

- 表单 `label-top`，大圆角输入，主按钮全宽墨色
- 登录页：左品牌短句 + 右表单（桌面），移动端单列；去掉炫光

### 2.6 服务页 / 落地页

- 已有模拟页结构可保留；去掉渐变色块 icon，改单色线框或单字标

## 3. 组件级规范（去 Element 脸）

| 组件 | 规范 |
|------|------|
| 主按钮 | 墨底白字，高 44，圆角 999 或 10；hover 微抬 1px |
| 次按钮 | 白底细边框 |
| 芯片 | 透明底 + 细边；active = 墨底 |
| 商品卡 | 无投影默认；hover 仅边框加深或极轻阴影；禁止夸张上浮 |
| 封面 | 统一比例；无图时用克制几何占位（按技术栈一色，忌彩虹） |
| 区块标题 | 纯文字 + 可选右侧「查看全部 →」；**删除左侧色条** |
| 价格 | `font-variant-numeric: tabular-nums`；主价墨或暗红褐 |

封装建议（新建）：

- `StoreButton.vue`
- `FilterChip.vue`
- `ProductCard.vue`（统一首页/列表/相关）
- `SectionHeader.vue`

业务页尽量用这些，而不是散落 Element 皮肤。

---

## 4. 动效（有意图的 2～3 个）

1. Hero 文字：进入时短距上移 + fade（200–400ms，ease-out）  
2. 商品卡：hover 封面轻微 scale(1.03)，整卡不动或仅 1px  
3. 页面切换：现有 page transition 保留，缩短时长，避免闪白  

禁：无限弹跳、强 glow、大面积 parallax。

---

## 5. 内容与信任（高级感的一半是文案）

- 全站去掉装饰 emoji（公告、销量、步骤）
- 商品标题模板统一：`【技术栈】业务名`，少感叹号
- 详情「演示路径」三步写清（学习向、合规）
- 页脚与关于：Gitee 互链，强化「可对照、可运行」而非促销口号

## 7. 实施分期（建议）

### Phase A — 气质底座（1～2 天）★ 先做
字体接入、token 收束、全局按钮/卡片/标题规范、去 emoji 竖条。  
**验收：** 任意页截图，关掉彩色后仍像「一个品牌」。

### Phase B — 首页英雄（1～2 天）
首屏瘦身、主视觉、CTA 重构、分类/技术栈降噪、商品卡统一。  
**验收：** 首屏 3 秒能说清「这是什么店」；无数据墙、无券条。

### Phase C — 列表/详情（1～2 天）
筛选、购买条、详情排版。  
**验收：** 从列表进详情到加购，路径视觉连续。

### Phase D — 交易闭环页（1 天）
登录/购物车/结算/支付成功页统一。  
**验收：** 无「后台表单」脸。

### Phase E — 动效与打磨（0.5～1 天）
入场、hover、移动端安全区与底栏对齐。  
**验收：** 动效少而准；手机首屏不挤。

## 9. 风险与取舍

| 风险 | 应对 |
|------|------|
| 字体包体积 | 仅子集 + woff2；展示字只加载 1～2 个字重 |
| 主视觉素材不足 | 先用 1 个精品项目高清截图 + 暗色遮罩；后续再换 |
| 业务要强推优惠券 | 入口放到「我的」或列表顶，**永不进 Hero** |
| Element 深度样式难盖 | 关键路径逐步换自研组件，表单保留 Element |

---

## 10. 建议决策（请你拍板）

1. **展示字体**：偏现代黑体（普惠体/思源黑）还是带一点编辑感（文楷仅标题）？  
2. **Hero 主视觉**：用「多项目拼贴」还是「单项目沉浸大图」？  
3. **价格颜色**：跟墨色高级风，还是保留一点红色促转化？  
4. **是否立即进入 Phase A+B 开工**？

你确认 1～3 后，可按分期直接改代码；若全部授权默认，则采用：  
**思源黑体系 + 单项目沉浸大图 + 主价墨色/辅价灰 + 立即做 A+B。**
