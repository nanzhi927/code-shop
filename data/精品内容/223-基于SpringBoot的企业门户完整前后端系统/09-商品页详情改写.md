## 卖点前置文案（放详情最顶部）

**基于 SpringBoot 的企业门户完整前后端系统**
前台是企业官网，后台是完整管理系统，一套代码两件事全包。
含 Shiro 权限体系 + Activiti 工作流引擎 + 代码生成器 + Druid 监控，44 张数据库表自带示例数据，导入即可运行。
附带数据库脚本、运行说明、8 张截图与真机演示视频。

## 一、功能模块（分组）

**前台栏目（5 个）**
1. **首页**：轮播图、公司简介、产品推荐、公司新闻、网站公告、客户案例
2. **关于我们**：公司简介 / 企业文化 / 经营理念（图文内容由后台配置）
3. **产品展示**：产品列表（卡片分栏）+ 产品详情页
4. **新闻中心**：按类型分类（公司新闻 / 行业资讯 / 客户案例 / 公告），点击阅读正文
5. **联系我们**：公司地址、联系电话、在线留言表单

**后台管理（8 个分组 / 20 个功能点）**
1. **基础管理**：文件管理、数据字典
2. **系统管理**：系统菜单、用户管理、角色管理、部门管理
3. **系统工具**：代码生成、计划任务（Quartz）
4. **系统监控**：系统日志、运行监控（Druid）、在线用户
5. **文章管理**：文章信息管理（富文本编辑，区分新闻/资讯/案例/公告）
6. **产品管理**：产品图片管理
7. **轮播图管理**：首页轮播图管理、轮播图类型管理
8. **基础信息配置**：公司简介设置、企业文化设置、经营理念设置

---

## 二、技术特点

- **前后台一体**：前台用 Thymeleaf 服务端渲染企业官网，数据全部来自后台维护，改内容不改代码
- **权限体系**：基于 Apache Shiro 的 RBAC，用户—角色—菜单三级，支持按钮级权限（perms 标识），不同角色登录看到不同菜单
- **工作流引擎**：集成 Activiti 5.22.0，含引擎、在线流程设计器（modeler）与流程轨迹图（diagram-rest）
- **代码生成器**：内置 Velocity 模板代码生成，可对数据库表批量生成 CRUD 代码，方便二次开发
- **运维监控**：Druid SQL 监控、AOP 操作日志、在线用户查看、Ehcache/Redis 缓存
- **前端组件齐全**：jQuery、jQuery Validation、summernote 富文本、bootstrapTable 数据表格、layer 弹出层、jsTree 树控件
- **XSS 防护**：集成 jsoup 做 XSS 过滤

## 三、数据库表概览

MySQL 数据库 `admin1`，共 **44 张表**，分为三类：

**门户业务表（4 张）**
- `a_news`：文章内容（type 区分公司新闻/行业资讯/客户案例/公告）
- `a_product_pic`：产品图片与简介
- `a_index_pic`：首页轮播图
- `a_pic_type`：轮播图类型

**系统 / 权限表（sys_*，11 张）**
`sys_user`（用户）、`sys_role`（角色）、`sys_menu`（菜单）、`sys_dept`（部门）、`sys_dict`（字典）、`sys_file`（文件）、`sys_log`（日志）、`sys_task`（任务）、`sys_user_role`、`sys_role_menu`、`sys_user_plus`

**工作流与其他表（29 张）**
- `act_*`：Activiti 工作流引擎表（25 张）
- `oa_notify` / `oa_notify_record`：站内通知
- `salary`：薪资流程演示表
- `blog_content`：博客内容表（脚手架自带）

## 四、运行环境

| 项目 | 要求 |
|---|---|
| 编程语言 | Java（JDK 1.8 及以上） |
| 核心框架 | SpringBoot 2.0.3.RELEASE |
| 持久层 | MyBatis 3.4.4 |
| 安全框架 | Apache Shiro 1.3.2 |
| 模板引擎 | Thymeleaf |
| 连接池 | Alibaba Druid 1.0.28 |
| 工作流 | Activiti 5.22.0 |
| 数据库 | MySQL 5.5 / 5.7 / 8.0 |
| 缓存 | Ehcache、Redis |
| 操作系统 | Windows / MacOS |
| 开发工具 | IDEA、Eclipse 均可 |
| Maven | 无版本要求 |

**启动方式**：`mvn spring-boot:run` 或打包 `java -jar`
**访问地址**：默认端口 80（如被占用或权限不足，可改为 8080/18080 等，修改 `application.yml` 的 `server.port`）；前台 `http://localhost/home`；后台 `http://localhost/index`
**后台账号**：默认管理员 admin / 1；另有测试账号 test / 111111（登录页可能预填 111111，请以 admin / 1 登录）
