## 三、数据库统计与分类（出处：数据库脚本/admin1.sql）

- 库名 `admin1`，共 **44 张表**，含 DROP/CREATE 与示例数据
- 分类：
  - Activiti 工作流表 `act_*`：25 张
  - 系统表 `sys_*`：11 张（sys_dept、sys_dict、sys_file、sys_log、sys_menu、sys_role、sys_role_menu、sys_task、sys_user、sys_user_plus、sys_user_role）
  - 业务表：a_index_pic（轮播图）、a_news（新闻）、a_pic_type（轮播图类型）、a_product_pic（产品图片）
  - 其他：oa_notify / oa_notify_record（站内通知）、salary（薪资流程演示）、blog_content（模板自带博客表）

## 四、运行方式与端口（已核实 application.yml / application.yml.bak）

- **原始默认端口：80**（application.yml.bak 可查证）；当前工程内 application.yml 被改为 18080，系录制演示视频时修改，**不是原始值**
- 端口修改位置：`src/main/resources/application.yml` 的 `server.port`
- 启动：`mvn spring-boot:run` 或 `mvn clean package -DskipTests && java -jar target/bootdo-2.0.0.jar`
- 配置文件：application-dev.yml（数据库账号密码、Redis 地址默认本机 6379、上传目录 `bootdo.uploadPath=c:/var/uploaded_files/`）
- 访问路由：前台 `/home`（HomeController），后台 `/index`（LoginController），登录页 `/login`
- 环境：JDK 1.8+，MySQL 5.5/5.7/8.0，Windows/MacOS，Maven 无版本要求
