## 简介（含真实功能清单、技术栈、时间轴 5 段、源码获取方式）

**项目简介**
基于 SpringBoot 2.0.3 的企业门户完整前后端系统，前台是对外的企业官网，后台是功能齐全的管理系统，一套代码同时覆盖「展示 + 管理」。默认端口 80（如被占用或权限不足，可改为 8080/18080 等），数据库 MySQL（脚本自带 44 张表、含示例数据）。

**功能清单**
- 前台栏目：首页（轮播图/公司简介/产品/新闻/公告/客户案例）、关于我们（公司简介·企业文化·经营理念）、产品展示（列表+详情）、新闻中心（公司新闻/行业资讯/客户案例/公告分类）、联系我们（含在线留言表单）
- 后台功能：文件管理、数据字典、用户管理、角色管理、系统菜单、部门管理、代码生成、计划任务、系统日志、Druid 运行监控、在线用户、文章信息管理、产品图片管理、首页轮播图管理、轮播图类型管理、公司简介/企业文化/经营理念配置
- 权限体系：Apache Shiro，角色-菜单-按钮级权限
- 工作流：Activiti 5.22.0（引擎 + 在线流程设计器 + 流程轨迹图）

**技术栈**
Java / JDK 1.8 · SpringBoot 2.0.3.RELEASE · MyBatis 3.4.4 · Apache Shiro 1.3.2 · Thymeleaf · Druid 1.0.28 · Activiti 5.22.0 · Quartz 2.2.1 · Ehcache + Redis · MySQL；前端 jQuery / jQuery Validation / summernote / bootstrapTable / layer / jsTree。

**时间轴（5 段）**
- 00:00 项目启动与前台首页总览（服务运行在默认端口 80）
- 00:32 前台各大栏目浏览（关于我们 / 产品展示 / 新闻中心 / 联系我们）
- 01:01 后台登录与 Shiro 权限拦截演示（未登录自动跳登录页）
- 01:47 后台核心管理功能（用户/角色/菜单/文章管理）
- 02:26 运行环境与部署步骤总结（JDK、导库、改配置、Maven 启动）
