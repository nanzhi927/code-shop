### 商品详情页文案（1200-2000 字）

**三大卖点，先看这里**

1. **带调度环节的全流程系统**：填发货单 → 生成运单 → 调度车辆与司机 → 物流状态流转 → 按单号跟踪签收，业务有"动线"，比普通增删改查系统多一个技术故事。
2. **实测可跑，材料较全**：本机实测运行通过，附运行截图、论文文件、PPT；跑不起来把报错发我，远程帮看。
3. **数据库设计有讲头**：10 张表，状态枚举全走数据字典表（加状态不改代码），预留定时任务线程，可扩展性的现成案例。

**项目简介**

基于 SpringBoot 2.2.2 的物流管理系统：管理员/用户双角色，同一 Maven 工程完成。管理员账号 admin，用户账号 a1（密码 123456），可直接登录演示双角色视角。

**功能模块（分组逐条）**

用户端：
✅ 发货单：填写送货地点、收件人、联系电话，生成运单
✅ 运单管理：运单列表与状态维护（寄件/发货/签收）
✅ 物流跟踪：按运单号/物流单号查询物流状态与进度
✅ 公告查看、个人中心

管理端：
✅ 运单管理：运单信息维护、状态更新
✅ 物流信息管理：物流记录维护（物流单号、关联运单、负责车辆、负责司机、物流状态）
✅ 车辆管理 / 司机管理：运力资源增删改查
✅ 用户管理：用户账号维护
✅ 基础数据管理：数据字典维护（运单状态/物流状态/车辆状态/性别/公告分类等）
✅ 公告管理、个人中心

业务主线：用户发货单 → 生成运单 → 管理员分配车辆+司机 → 物流记录生成、状态流转 → 用户按单号跟踪。一张运单对应多条物流记录（揽收→运输→派送），"运单-物流记录-车辆/司机"构成 ER 图核心三角。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis（starter 2.1.1）+ MyBatis-Plus 2.3；Apache Shiro 1.3.2；Thymeleaf；spring-boot-devtools 热部署；FastJSON 1.2.8；Hutool 4.0.12；Apache POI 3.9（Excel 扩展点）；前端 Vue + Element-UI（含 dist 构建产物与一键安装/运行/构建 bat 脚本）；主启动类 com.wuliuguanliwuApplication。学过 SSM 的上手很快。

**数据库说明**

库名 wuliuguanliwu，共 10 张表：系统支撑 3 张（config/token/users）、数据字典 1 张（dictionary，所有状态枚举）、公告 1 张（news）、业务 5 张（用户 yonghu、运单 yundan、物流信息 wuliu、车辆 cheliang、司机 siji）。脚本含 DROP/CREATE 与示例数据，重复导入不冲突。

两个设计亮点（答辩可直接讲）：
- 数据字典驱动：状态下拉动态渲染，新增状态只加数据不改代码；
- 定时任务架构预留：ServletContextListener + 常驻线程 MyThreadMethod，可扩展"超时运单自动更新"（当前为预留实现，如实说明）。

**运行环境**

JDK 1.8+、Maven、MySQL 5.7+；Windows/MacOS 均可，IDEA/Eclipse 均可。启动流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → 运行主类或 `mvn spring-boot:run`。默认端口 8080，访问 /admin/dist/index.html 登录。
