### 商品描述（600-1000 字）

【项目定位】
一套带"调度环节"的 SpringBoot 物流管理系统：用户填发货单生成运单，管理员调度车辆和司机，物流状态一路流转到签收，用户按单号跟踪。本机实测跑通才上架，运行截图可以直接看效果。

【功能清单·用户端】
✅ 发货单：填写送货地点、收件人、联系电话，生成运单
✅ 运单管理：寄件、发货、签收状态维护
✅ 物流跟踪：按运单号/物流单号查询物流状态与进度
✅ 公告查看、个人中心

【功能清单·管理员后台】
✅ 运单管理：运单信息维护、状态更新
✅ 物流信息管理：物流记录（物流单号、负责司机、车辆、物流状态流转）
✅ 车辆管理 / 司机管理：运力资源维护
✅ 用户管理、基础数据管理（数据字典：运单状态/物流状态/车辆状态/性别/公告分类）
✅ 公告管理、个人中心

管理员账号 admin，用户账号 a1（密码 123456），可以直接登录演示双角色。

【技术栈】
SpringBoot 2.2.2 + MyBatis + MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + Thymeleaf + FastJSON + Hutool + Apache POI，JDK 1.8；前端 Vue + Element-UI（带构建产物和一键 bat 脚本）。标准 Maven 工程，供学习交流用。
