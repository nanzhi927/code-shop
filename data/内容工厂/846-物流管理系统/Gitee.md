# 物流管理系统-SpringBoot（毕设学习版）

基于 SpringBoot 的物流管理系统**教学版**：**管理员 / 用户**双角色，覆盖"填发货单 → 生成运单 → 调度车辆与司机 → 物流状态流转 → 按单号跟踪签收"全流程，数据库 10 张表导入即用，适合毕业设计、课程设计的学习参考与技术交流。

> 本仓库为教学版，供学习交流使用；完整版（含全部资料、论文文件、PPT、运行说明与答疑）获取方式见文末引导。

## 项目简介

- **用户端**：填发货单（送货地点/收件人/联系电话生成运单）、运单管理（寄件/发货/签收）、物流跟踪（按运单号/物流单号查询）、公告查看、个人中心。
- **管理端**：运单管理、物流信息管理（物流单号/负责司机/车辆/物流状态）、车辆管理、司机管理、用户管理、基础数据管理（数据字典）、公告管理、个人中心。
- **数据库**：MySQL，库名 `wuliuguanliwu`，10 张表（系统支撑 3 + 数据字典 1 + 公告 1 + 业务 5），脚本自带建表语句与示例数据，导入即用。
- **工程**：标准 Maven 结构，JDK 1.8，SpringBoot 2.2.2.RELEASE，主启动类 `com.wuliuguanliwuApplication`。

## 数据库设计

库名 `wuliuguanliwu`，共 10 张表，按用途分四类：

| 分类 | 数量 | 说明 |
|---|---|---|
| 系统支撑表 | 3 张 | `config`（参数配置）、`token`（登录令牌）、`users`（管理员账号） |
| 数据字典 | 1 张 | `dictionary`——运单状态、物流状态、车辆状态、性别、公告分类等所有枚举值，页面下拉动态渲染 |
| 公告 | 1 张 | `news` |
| 业务表 | 5 张 | 用户 `yonghu`、运单 `yundan`、物流信息 `wuliu`、车辆 `cheliang`、司机 `siji` |

关键表字段：
- `yundan`（运单）：送货地点、收件人、联系电话、运单状态、创建时间；
- `wuliu`（物流信息）：物流单号、关联车辆、关联运单、负责司机、物流状态、创建时间。

关系设计：一张运单对应多条物流记录（揽收→运输→派送），车辆与司机挂在物流记录上（多对一）——"运单-物流记录-车辆/司机"就是 ER 图的核心三角。

两个值得单独讲的设计：
1. **数据字典驱动**：所有状态枚举存 dictionary 表，前端下拉动态加载，新增状态只加数据不改代码（可扩展性的具体落点）；
2. **定时任务架构预留**：`ServletContextListener` 在启动时初始化，`MyThreadMethod` 常驻线程循环为"按时间自动更改单据状态"类需求预留（当前线程体为空实现，如实说明）。

ER 图建议两层：业务层（运单-物流记录-车辆-司机关系图，核心必画）、字典层（dictionary 与各业务表状态字段关联示意）。

## 快速开始

第 1 步：导入数据库

```sql
create database wuliuguanliwu default character set utf8;
use wuliuguanliwu;
source 你的路径/db.sql;
```

或命令行直接导入：

```bash
mysql -u用户名 -p wuliuguanliwu < db.sql
```

导入后应能看到 10 张表；表数量不足说明脚本未导完，重新导入即可。

第 2 步：修改配置。打开 `src/main/resources/application.yml`：
- 数据库连接：`jdbc:mysql://127.0.0.1:3306/wuliuguanliwu`（连接串已带 serverTimezone=GMT%2B8），username/password 改成你自己的（工程默认 root/123456）；
- 端口：默认 8080，被占用可修改 `server.port`。

第 3 步：启动

```bash
mvn spring-boot:run
```

或 IDEA 中直接运行主类 `com.wuliuguanliwuApplication`。

第 4 步：访问验证
- 后台登录页：`http://localhost:8080/wuliuguanliwu/admin/dist/index.html`
- 工程内置演示账号与数据库演示数据，登录后请及时修改密码

前端 Vue 工程修改说明：admin 目录内有 `1-install.bat`（装依赖）、`2-run.bat`（本地运行）、`3-build.bat`（打包），Windows 下按序执行；改了 src 源码必须重新 build 才会生效。

## 常见问题（FAQ）

**Q1：启动报数据库连接失败（Access denied / Communications link failure）？**
九成是 application.yml 里数据库密码/库名没改对，或 MySQL 服务未启动。先在命令行用同样账号密码登录 MySQL 验证。

**Q2：报端口被占用（Port 8080 was already in use）？**
把 `server.port` 改成其他未占用端口，或关闭占用 8080 的进程。

**Q3：上传的图片显示不出来？**
工程明确要求上传目录（src/main/webapp/upload）里的文件名不能含中文，重命名为英文/数字后重新上传。

**Q4：改了页面没生效？**
后台是 Vue 工程，`dist` 是构建产物；修改 `src` 下源码后需执行 `3-build.bat` 重新打包（或 npm run build）。

**Q5：Maven 依赖下载慢或工程报红？**
配置国内镜像源（如阿里云 Maven 镜像），删除本地仓库中下载不完整的目录后重新 update；IDEA 导入后等待依赖全部下载完成再看报错。

**Q6：10 张表分别是干什么的？**
见"数据库设计"一节的四分类与表名清单；导完表数量不足 10 说明脚本没导完。

**Q7：运单和物流记录是什么关系？**
一对多：一张运单对应多条物流记录（揽收/运输/派送），每条记录挂负责车辆与司机；物流跟踪就是按运单号/物流单号查这些记录的状态。

**Q8：MyThreadMethod 线程是干什么的？**
架构预留：常驻线程循环，注释写明用于"按时间自动更改单据状态"类定时任务（如超时自动更新），当前线程体为空实现，可按需扩展。

**Q9：有论文吗？**
工程附带的论文文件（doc）是通用内容，请按自己的题目改写后使用；论文请独立完成，仓库仅提供学习参考。

**Q10：支持 MySQL 8 吗？**
说明文档标注 5.7 及以上可用；MySQL 8 注意时区配置（application.yml 连接串已带 serverTimezone 参数）。
