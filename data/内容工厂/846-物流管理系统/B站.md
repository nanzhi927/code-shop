### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 物流管理系统：用户填发货单生成运单，管理员调度车辆和司机，物流状态一路流转到签收，用户按单号跟踪。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis（starter 2.1.1）+ MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + Thymeleaf + FastJSON + Hutool + Apache POI，JDK 1.8；前端 Vue + Element-UI（带构建产物和一键 bat 脚本）。标准 Maven 工程，供学习交流用。

【完整功能清单】
用户端：发货单填写（送货地点/收件人/联系电话）、运单管理（寄件/发货/签收）、物流跟踪（按运单号/物流单号查询）、公告查看、个人中心。
管理员后台：运单管理、物流信息管理（物流单号/负责司机/车辆/物流状态）、车辆管理、司机管理、用户管理、基础数据管理（数据字典）、公告管理、个人中心。

【数据库说明】
库名 wuliuguanliwu，脚本自带 10 张表（系统支撑 3 张 + 数据字典 1 张 + 公告 1 张 + 业务 5 张：用户/运单/物流信息/车辆/司机）+ 示例数据，建库导脚本即可用。管理员账号 admin/admin，用户账号 a1/123456。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7+；Windows/MacOS。启动：IDEA 运行主类 wuliuguanliwuApplication，或 mvn spring-boot:run。默认端口 8080，访问 /admin/dist/index.html 登录。

**【0:20-1:10 用户端发货】**（画面：a1 登录 → 填发货单：送货地点/收件人/联系电话 → 提交生成运单）

**【1:10-2:50 管理员调度】**（画面：admin 登录 → 运单管理 → 物流信息管理新建记录：选车辆、选司机、更新物流状态）
