> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13，实际读取源码目录 D:\从戎网站源码\springboot源码\1\springboot208基于springboot物流管理系统--论文pf）。

## 一、技术栈与版本
- Java 1.8；SpringBoot 2.2.2.RELEASE（spring-boot-starter-parent 2.2.2）；MyBatis（mybatis-spring-boot-starter 2.1.1）+ MyBatis-Plus 2.3；Apache Shiro 1.3.2；Thymeleaf（模板/静态资源）；spring-boot-devtools（热部署）；FastJSON 1.2.8；Hutool 4.0.12；Apache POI 3.9（Excel 套件）；百度 AI SDK（java-sdk 4.4.1）；mysql-connector-java
- 前端：Vue + Element-UI（admin 单端 SPA，含 dist 构建产物，源码在 src/main/resources/admin/admin，附 1-install.bat / 2-run.bat / 3-build.bat 脚本）
- 工程为标准 Maven 结构，主启动类 `com.wuliuguanliwuApplication`

## 二、功能模块
- **前台（说明文档所列）**：首页（轮播图）、发货单（用户填写）、公告、物流跟踪（按单号查询）、个人中心。⚠️ 工程内未发现独立 front 静态页目录，运行必读只给后台登录地址；用户端功能经 admin Vue 端登录使用（如实表述，不编造前台地址）
- **后台（管理员）**：个人中心；基础数据管理（车辆/司机/用户/数据字典）；公告管理；司机管理；车辆管理；物流信息管理；用户管理；运单管理
- **后台（用户）**：个人中心；公告管理（查看）；物流信息管理（查看物流状态、预计到达）；运单管理（下单/发货/签收）
- **后台 Vue 模块目录（实际扫描）**：cheliang、config、dictionary（含车辆状态/公告分类/性别/物流状态/运单状态等字典子模块）、news、siji、users、wuliu、yonghu、yundan
- **业务主线**：用户填发货单 → 生成运单（收件人/送货地点/联系方式/运单状态）→ 管理员调度车辆+司机 → 产生物流记录（物流单号+物流状态流转）→ 用户按单号跟踪物流

## 三、数据库
- 库名 `wuliuguanliwu`，脚本 db.sql 共 **10 张表**（系统支撑表 3：config/token/users；数据字典 1：dictionary，含运单状态/物流状态/车辆状态/性别/公告分类等枚举；公告 1：news；业务表 5：用户 yonghu、运单 yundan、物流信息 wuliu、车辆 cheliang、司机 siji）
- 关键表字段：`yundan`（运单：送货地点、收件人、联系方式、运单状态）；`wuliu`（物流单号、车辆、运单、负责司机、物流状态）
- 脚本含 DROP/CREATE 与示例数据，导入即用

- 环境：JDK 1.8+、Maven、MySQL 5.7+；Windows/MacOS 均可；IDEA/Eclipse 均可；推荐谷歌浏览器
