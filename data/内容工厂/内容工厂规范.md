# 内容工厂规范 v2（定稿）

> v1 的教训：把"卖源码"当目标 → 内容像广告、重复、不可搜、没信任、违规词多、定价错。
> v2 的核心转向：**内容不是为了卖源码，而是为了"加到微信 + 建立信任 + 引导定制需求"**。
> 源码可以是免费/低价引流品；**定制开发才是利润核心（500-3000+）**。

## 二、内容战略：信任优先，定制转化

### 2.1 每篇内容的 CTA 优先级（从高到低）
1. **加微信免费咨询/免费评估需求**（最高优先，一切内容的终点）
2. **定制需求**（"要改成自己的题目/加功能/换技术栈，可以问我怎么做"）
3. **低价引流款**（闲鱼 6-9.9，或免费送源码换微信）
4. 正价源码（自建站 30-99+）

### 2.2 信任怎么建（每篇至少落 2 条）
- **给证据不给形容词**：真实后台截图、演示视频（可先看再买）、运行日志、环境要求
- **主动说缺点**：如"论文没有只有源码""需要自己装 MySQL"——反向可信度最高
- **过程透明**：怎么跑、遇到报错怎么办、跑不起来怎么处理（"跑不起来我远程帮你"）
- **低门槛承诺**：先看演示、先小额、先付定金；不满意可换同价项目
- **社会证明**：成交/答疑截图（打码）、"同校同学买过"、代理/学长身份
- **免费价值前置**：选题清单、开题模板、报错手册先免费给（换微信）
- **人设**：不是"卖家"，是"做毕设的学长/技术人"，用第一人称讲自己的经历

### 2.3 受众视角写法（学生视角的痛点清单，任选切入）
- 选题被导师打回、不知道做什么
- 不会写代码/时间不够/要实习要考研
- 代码跑不起来（环境/数据库/端口）
- 答辩讲不清技术点
- 怕被骗（付钱不给源码、给的是残缺/不能跑的）
- 预算有限（学生）

**写法要求**：先共情（"我也经历过…"）→ 再给证据 → 再给方案（免费/低价/定制）→ 最后才知道点。

## 三、违禁词与合规（发布前必查，00-通用素材/02 有完整表）

### 3.1 高危禁用词（一律不写）
| 类别 | 禁用示例 | 替代写法 |
|---|---|---|
| 学术违规 | 代做、代写、代写论文、包过、包答辩、保毕业、稳过 | 学习参考、技术交流、思路辅导、答疑 |
| 绝对化 | 最全、第一、唯一、顶级、永久、100%可运行 | 已实测、多套可选、实测可跑 |
| 导流违规 | 正文写微信/QQ/加我/私聊发链接、贴站外链接 | 看主页、私信我、评论区扣 1（链接只放主页/简介） |
| 低价诱导 | 免费送、白嫖、白菜价、1 元秒杀 | 学生友好、入门价位、可先看演示 |
| 版权风险 | 破解、破解版、盗版、全网最全 | 学习版、教学示例 |
| 提他平台 | 在小红书提闲鱼/淘宝；在 B 站提微信 | 只说"主页""私信"，不点名别的平台 |
| 医疗/金融/迷信 | （本项目不涉及，但仍需避开"稳赚""暴富"） | — |
| 煽动焦虑过度 | 不做毕设就毕不了业、导师会挂你 | 早准备更省心、时间更充裕 |

### 3.2 各平台特别注意
- **小红书**：正文不出现联系方式/链接；用"主页""私信""评论区扣1"；不要连续硬广；笔记不要带价格对比词
- **闲鱼**：虚拟商品按类目发布；不写"代做/论文代写"；描述避免"永久""包更新"；引导到自建站看演示
- **抖音**：简介/评论导流；不要说"加微信"直接连写；用"主页"
- **B站**：简介可以放链接（相对宽松），但避免"代做"
- **知乎**：正文外链易限流，用"个人简介/评论置顶"承接

## 五、分渠道定价（关键！v1 完全错了）

| 渠道 | 定价 | 目的 | 说明 |
|---|---|---|---|
| **闲鱼** | **6 元 / 9.9 元** | 起号、跑量、拿信任 | 低价款只含源码+数据库，答疑/部署另收费；详情里说明 |
| **自建站** | **30-99+ 元** | 利润款 | 含源码+资料+说明+售后答疑；可加"远程部署 +50"、"一对一讲解 +100" |
| **Gitee/GitHub** | **免费**（部分项目开源） | 引流+背书 | 只放教学版/脱敏版；README 引到自建站与定制服务 |
| **定制开发** | **500-3000+** | 利润核心 | 改题目/加功能/换技术栈/全新开发 |
| 增值服务 | 部署 +50-100、讲解 +100-200、论文格式辅导 +100-300 | 提客单价 | 学生最痛的是"跑不起来" |

**闲鱼低价的正确用法**：9.9 卖源码 → 加微信 → 交付时提供"远程部署 50 元 / 讲解 100 元" → 有定制需求直接转定制（这才是赚钱点）。

## 六、语言要求
- **全中文**（GitHub 也用中文，受众是中国大学生），技术栈名词可保留英文
- 口语自然，不堆砌营销词；小红书可以口语+emoji，B站/知乎技术向，闲鱼交易向
- 禁止空洞套话（"功能强大""应有尽有"）——每个卖点都要有具体证据
