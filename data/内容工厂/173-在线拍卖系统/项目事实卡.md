# 项目事实卡：173 基于SpringBoot的在线拍卖系统

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13）。

## 一、技术栈与版本（pom.xml 实测）
- Java 1.8；SpringBoot **2.2.2.RELEASE**（spring-boot-starter-parent）
- MyBatis：mybatis-spring-boot-starter **2.1.1**；MyBatis-Plus **2.3**（mybatisplus-spring-boot-starter 1.0.5）
- Apache Shiro **1.3.2**（shiro-spring）；MySQL mysql-connector-java（随 parent 版本）
- 工具库：fastjson 1.2.8、hutool-all 4.0.12、commons-lang3 3.0、commons-io 2.5、protobuf-java 3.10.0、validation-api 2.0.1
- 百度 AI SDK：com.baidu.aip java-sdk 4.4.1（utils 中有 BaiduUtil，工程集成了百度人工智能接口能力）
- 前端：Vue 2.6.10（admin 端 package.json 实测）+ Element UI + axios 0.19.2；前台 front 使用 layui + elementui 静态资源
- 标准后端分层：controller / dao / entity / service / interceptor / annotation（IgnoreAuth、LoginUser 自定义注解）/ utils

## 二、功能模块（Controller + 运行必读 双重核实）
- **角色 2 种**：用户、管理员；前后台分离
- **前台（用户）5 个栏目**：首页（热门拍卖商品、最新竞拍公告）、拍卖商品（浏览/详情/参与竞拍）、竞拍公告（拍卖规则、竞拍时间）、留言反馈、个人中心
- **后台（用户）**：个人中心；历史竞拍管理；竞拍订单管理；留言板管理
- **后台（管理员）**：个人中心；用户管理；商品类型管理；拍卖商品管理（含审核，字段含商品名称/类型/图片/价格/商品详情/活动时间/活动状态）；历史竞拍管理；竞拍订单管理；留言板管理；系统管理（轮播图管理、竞拍公告发布）
- Controller 清单（11 个）：Common、Config、File、Jingpaidingdan（竞拍订单）、Lishijingpai（历史竞拍）、Messages（留言）、News（公告）、Paimaishangpin（拍卖商品）、Shangpinleixing（商品类型）、User（管理员）、Yonghu（用户）

## 三、数据库（db.sql 实测）
- 库名 `springbootp0eo6`，脚本共 **10 张表**：config（系统配置/轮播图）、jingpaidingdan（竞拍订单）、lishijingpai（历史竞拍）、messages（留言反馈）、news（竞拍公告）、paimaishangpin（拍卖商品）、shangpinleixing（商品类型）、token（登录令牌）、users（管理员）、yonghu（用户）
- 表分类：业务表 6（商品/类型/订单/历史竞拍/留言/公告）+ 系统表 4（config/token/users/yonghu）
- 含 DROP/CREATE 与示例数据，导入即用

## 四、运行（application.yml 实测）
- **默认端口 8080**，context-path：`/springbootp0eo6`
- 数据库：MySQL，库名 springbootp0eo6，配置文件中 root/123456（需按本机修改密码）
- 前台：`http://localhost:8080/springbootp0eo6/front/index.html`
- 后台：`http://localhost:8080/springbootp0eo6/admin/dist/index.html`
- 启动：IDEA 导入后运行 `SpringbootSchemaApplication`，或 `mvn spring-boot:run`
- 环境：JDK 1.8+、MySQL 5.7/8.0、Maven；Windows/macOS；推荐谷歌浏览器
