**项目简介**

基于 SpringBoot 2.2.2 的在线拍卖系统：前台是拍卖网站（5 栏目），后台是完整管理端（用户端+管理员端两种后台），用户/管理员两种角色，同一个 Maven 工程提供接口。基于通用脚手架风格二次开发，供学习交流使用。管理员账号 abo（见说明文档）。

**功能模块（分组逐条）**

前台（拍卖网站，5 栏目）：
✅ 首页：热门拍卖商品 + 最新竞拍公告
✅ 拍卖商品：商品列表 + 详情页，可参与竞拍
✅ 竞拍公告：拍卖规则、竞拍时间
✅ 留言反馈：提交意见与管理员互动
✅ 个人中心：用户资料管理

后台（用户端）：
✅ 个人中心：资料管理
✅ 历史竞拍管理：本人竞拍记录
✅ 竞拍订单管理：订单查看与状态处理
✅ 留言板管理：本人留言管理

后台（管理员端）：
✅ 用户管理：注册用户维护
✅ 商品类型管理：拍卖分类维护
✅ 拍卖商品管理：添加/编辑/审核，设置活动时间与活动状态
✅ 历史竞拍管理：全站竞拍记录
✅ 竞拍订单管理：全站订单处理
✅ 留言板管理：回复用户反馈
✅ 系统管理：轮播图管理、竞拍公告发布

权限体系：Apache Shiro 实现角色区分（管理员/用户），token 登录态校验，接口层自定义注解鉴权。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；MySQL 5.7/8.0；前端 Vue 2.6 + Element UI + axios 0.19.2（后台管理端已打包 dist），前台另用 layui；工具库 fastjson/hutool/commons-lang3/commons-io；集成百度 AI SDK（预留扩展点）。学过 SSM 的上手很快。

**数据库说明**

库名 springbootp0eo6，共 10 张表：业务表 6 张（拍卖商品 paimaishangpin / 商品类型 shangpinleixing / 竞拍订单 jingpaidingdan / 历史竞拍 lishijingpai / 留言反馈 messages / 竞拍公告 news）+ 系统表 4 张（config / token / users / yonghu）。关键设计：拍卖商品表的"活动时间+活动状态"字段驱动竞拍窗口与前台展示逻辑。脚本含建表语句与示例数据，导入即用。

**运行环境**

JDK 1.8+、Maven、MySQL 5.7/8.0；Windows/macOS 均可，推荐谷歌浏览器。启动流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → 运行 SpringbootSchemaApplication（或 `mvn spring-boot:run`）。默认端口 8080，context-path 为 /springbootp0eo6：前台 `/springbootp0eo6/front/index.html`，后台 `/springbootp0eo6/admin/dist/index.html`。
