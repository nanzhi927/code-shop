### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 在线拍卖系统：前台是拍卖网站，后台是完整管理端，用户/管理员两种角色，拍卖全流程闭环。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考——尤其推荐怕选题撞车的同学，拍卖方向少见。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + MySQL，JDK 1.8；前端 Vue 2.6 + Element UI，前后端分离，后台管理端为打包好的 Vue 工程。标准 Maven 工程，接口统一返回封装，带自定义鉴权注解。基于通用脚手架风格二次开发，供学习交流用。

【完整功能清单】
前台 5 栏目：首页（热门拍卖商品+最新竞拍公告）、拍卖商品（浏览/详情/参与竞拍）、竞拍公告（规则与时间）、留言反馈、个人中心。
后台功能：
- 用户端：个人中心、历史竞拍管理、竞拍订单管理、留言板管理
- 管理员端：用户管理、商品类型管理、拍卖商品管理（含审核，可设活动时间/活动状态）、历史竞拍管理、竞拍订单管理、留言板管理、轮播图管理、竞拍公告发布

【数据库说明】
库名 springbootp0eo6，脚本 db.sql 共 10 张表：业务表 6 张（拍卖商品/商品类型/竞拍订单/历史竞拍/留言反馈/竞拍公告）+ 系统表 4 张（config/token/users/yonghu），含示例数据，导入即用。管理员账号 abo。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7/8.0；Windows/macOS。启动：运行 SpringbootSchemaApplication 或 mvn spring-boot:run。默认端口 8080，注意 context-path 是 /springbootp0eo6：前台 /springbootp0eo6/front/index.html，后台 /springbootp0eo6/admin/dist/index.html。
