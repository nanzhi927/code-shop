# 在线拍卖系统-SpringBoot（毕设学习版）

基于 SpringBoot 的在线拍卖系统**教学版**：包含**前台拍卖网站**（5 栏目）与**后台管理端**（用户端+管理员端），用户/管理员两种角色，拍卖业务全流程闭环，数据库 10 张表导入即用，适合毕业设计、课程设计的学习参考与技术交流。

> 本仓库为教学版，供学习交流使用；完整版（含论文参考文档、演示 PPT、运行截图、运行说明与答疑）获取方式见文末引导。

## 项目简介

- **前台**：拍卖网站，5 个栏目——首页（热门拍卖商品+最新竞拍公告）、拍卖商品（浏览/详情/参与竞拍）、竞拍公告（拍卖规则与竞拍时间）、留言反馈、个人中心。
- **后台（用户端）**：个人中心、历史竞拍管理、竞拍订单管理、留言板管理。
- **后台（管理员端）**：用户管理、商品类型管理、拍卖商品管理（含审核，可设活动时间/活动状态）、历史竞拍管理、竞拍订单管理、留言板管理、轮播图管理、竞拍公告发布。
- **业务闭环**：管理员审核上架商品并设定活动时间与活动状态 → 用户前台参与竞拍 → 系统生成竞拍订单 → 历史竞拍记录沉淀。
- **数据库**：MySQL，库名 `springbootp0eo6`，10 张表（业务表 6 + 系统表 4），脚本自带建表语句与示例数据，导入即用。
- **工程**：标准 Maven 结构，JDK 1.8，SpringBoot 2.2.2.RELEASE。

## 快速开始

第 1 步：导入数据库

```sql
create database springbootp0eo6 default character set utf8;
use springbootp0eo6;
source 你的路径/db.sql;
```

或命令行直接导入：

```bash
mysql -u用户名 -p springbootp0eo6 < db.sql
```

导入后应能看到 10 张表；表数量不足说明脚本未导完，重新导入即可。

第 2 步：修改配置。打开 `src/main/resources/application.yml`：
- 数据库连接：`username: root`、`password: 123456` 改成你自己的；
- 端口：默认 8080，context-path 为 `/springbootp0eo6`（一般不用改）。

第 3 步：启动

运行 `com.SpringbootSchemaApplication` 主类，或：

```bash
mvn spring-boot:run
```

第 4 步：访问验证
- 前台：`http://localhost:8080/springbootp0eo6/front/index.html`
- 后台：`http://localhost:8080/springbootp0eo6/admin/dist/index.html`
- 管理员账号：abo / abo（见说明文档）

看到启动完成日志即运行成功。

## 常见问题（FAQ）

**Q1：访问 404 / 页面空白？**
十有八九是没带 context-path。所有地址都要带 `/springbootp0eo6` 前缀，直接访问 8080 根路径是空白。

**Q2：启动报数据库连接失败（Access denied）？**
application.yml 里数据库密码是默认值，先改成你本机 MySQL 密码；先用命令行验证账号能否登录，确认 MySQL 服务已启动。

**Q3：MySQL 8 报时区错误？**
连接串里的 serverTimezone 参数保持 UTC 或改为 GMT%2B8，与数据库时区配置核对。

**Q4：Maven 依赖下载慢或工程报红？**
配置国内镜像源（如阿里云 Maven 镜像），删除本地仓库中下载不完整的目录后重新 update；IDEA 导入后等待依赖全部下载完成再看报错。

**Q5：前台用户账号是什么？**
运行文档未给出默认前台账号，可在前台注册；数据库 yonghu 表含示例数据可直接查看。

**Q6：竞拍是实时出价吗？**
当前实现为记录式竞拍（常规实现），未做高并发优化。答辩时如实说明实现边界，改进方向（分布式锁/消息队列）可作为论文"展望"素材。

**Q7：百度 AI SDK 是干什么的？**
工程集成了百度 AI 的 java-sdk 并封装了工具类，属于预留的能力扩展点，核心拍卖业务不依赖它。

**Q8：这个项目能用作毕业设计吗？**
可以作学习参考。基于通用脚手架风格二次开发，建议在其上做自己的业务改造，答辩时如实说明，能讲清原理比"从零手写"的说法更稳。

**Q9：有论文或 PPT 吗？**
本仓库（教学版）不含；完整版包含论文参考文档（docx）与演示 PPT（pptx），仅供学习参考，论文请独立完成。

**Q10：支持 MySQL 5.5 吗？**
文档标称 5.7/8.0，更低版本未验证，建议按 5.7+ 环境部署。
