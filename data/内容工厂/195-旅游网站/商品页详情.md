**项目简介**

基于 SpringBoot 2.2.2 的旅游网站：前台为面向用户的旅游线路浏览与预订页面，后台为 Vue 2.6 + Element UI 2.13 管理端，前后端分离架构（工程内前端均为构建产物，运行无需 Node 环境）。管理员账号 abo、前台测试用户"用户1"（密码见运行必读）。

**功能模块（分组逐条）**

前台（用户端，13 类功能）：
✅ 注册登录、首页轮播（后台可配）
✅ 旅游线路：列表/搜索/详情（景点/出发地/目的地/交通方式/行程路线/价格）
✅ 最新线路：独立栏目，列表+详情
✅ 线路分类：观光/度假/探险/文化/短程等分类浏览
✅ 线路收藏、线路评论
✅ 购物车：加购、修改数量、删除
✅ 下单支付：模拟支付流程，支持余额充值
✅ 我的订单：未支付/已支付/已完成状态流转
✅ 收货地址管理、在线客服（向管理员提问）、新闻资讯、个人中心

后台（管理端，13 组功能）：
✅ 用户管理：用户增删改查
✅ 旅游线路管理 / 最新线路管理：线路全字段维护（封面图、行程富文本）
✅ 线路分类管理
✅ 订单管理：查看订单、发货、状态维护
✅ 评论管理：两类线路评论查看与回复
✅ 新闻资讯管理：前台资讯的数据源
✅ 在线客服管理：回复用户提问
✅ 购物车 / 收藏 / 地址管理、轮播图配置、个人中心

核心业务链：前台浏览 → 加入购物车 → 生成订单（含商品快照）→ 模拟支付 → 后台订单管理发货。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；FastJson 1.2.8；Hutool 4.0.12；前台 Vue + ElementUI 页面，后台 Vue 2.6 + Element UI 2.13 + ECharts 4.6 + axios；数据库 MySQL 5.7/8.0。学过 SSM 的上手很快。

**数据库说明**

库名 springbootmt74k，共 15 张表：系统域 3 张（users 管理员 / token 登录令牌 / config 轮播与全局配置）、业务表 12 张（yonghu 用户、lvyouxianlu 旅游线路、zuixinxianlu 最新线路、xianlufenlei 线路分类、orders 订单、cart 购物车、address 收货地址、storeup 收藏、discusslvyouxianlu / discusszuixinxianlu 线路评论、chat 在线客服、news 新闻资讯）。脚本含建库语句与真实感示例数据（云南大理丽江 6 天 5 晚、桂林 4 天 3 晚等），导入即用，ER 图素材管够。

**运行环境**

JDK 1.8+、MySQL 5.7/8.0；Windows/macOS 均可。启动流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → IDEA 运行主类（或 `mvn spring-boot:run`）。前台 `http://localhost:8080/springbootmt74k/front/index.html`，后台 `http://localhost:8080/springbootmt74k/admin/dist/index.html`（推荐 Chrome）。
