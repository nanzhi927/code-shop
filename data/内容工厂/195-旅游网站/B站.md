### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 旅游网站：前台用户端 + 后台管理端双入口，业务链完整——浏览线路、收藏评论、加购物车、预订支付、后台订单管理，一个工程里搞定。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2，前台 Vue + ElementUI 页面，后台 Vue 2.6 + Element UI 2.13 + ECharts 4.6 管理端，JDK 1.8，标准 Maven 前后端分离工程（前端均为构建产物，运行不用装 Node）。数据库 MySQL，库名 springbootmt74k。

【完整功能清单】
前台（用户端）：注册登录、首页轮播（后台可配）、旅游线路浏览/搜索/详情、最新线路、线路分类、线路收藏、线路评论、购物车、预订支付（模拟支付+余额充值）、我的订单、收货地址、在线客服、新闻资讯、个人中心。
后台（管理端）：用户管理、旅游线路管理、最新线路管理、线路分类管理、订单管理（发货/状态）、评论管理（含回复）、新闻资讯管理、在线客服管理、购物车/收藏/地址管理、轮播图配置。

【数据库说明】
15 张表 = 系统表 3 张（管理员/令牌/配置）+ 业务表 12 张（用户、旅游线路、最新线路、线路分类、订单、购物车、地址、收藏、线路评论×2、在线客服、新闻）。脚本带示例数据（云南大理丽江 6 天 5 晚、桂林 4 天 3 晚等真实感线路），建库导入即用。

【运行环境】
JDK 1.8+、MySQL 5.7/8.0；Windows/MacOS。启动：建库导 db.sql → 改 application.yml 数据库密码 → IDEA 运行主类（或 mvn spring-boot:run）。前台 http://localhost:8080/springbootmt74k/front/index.html（测试用户"用户1"），后台 .../admin/dist/index.html（管理员 abo，密码见运行说明），推荐谷歌浏览器。
