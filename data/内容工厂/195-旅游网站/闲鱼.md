### 商品描述（600-1000 字）

【项目定位】
一套 SpringBoot + Vue 的旅游网站：前台用户端 + 后台管理端双入口，业务链完整——浏览线路→收藏评论→购物车→下单→模拟支付→后台订单管理。本机实测跑通才上架。

【功能清单·前台（用户端）】
✅ 注册登录、首页轮播（后台可配）
✅ 旅游线路：列表/搜索/详情（景点/出发地/目的地/交通/行程/价格）
✅ 最新线路栏目、线路分类浏览
✅ 线路收藏、线路评论
✅ 购物车：加购/改数量/删除
✅ 下单支付（模拟支付）+ 余额充值
✅ 我的订单（未支付/已支付/已完成）、收货地址管理
✅ 在线客服（向管理员提问）、新闻资讯、个人中心

【功能清单·后台（管理端）】
✅ 用户管理
✅ 旅游线路管理 / 最新线路管理（全字段维护）
✅ 线路分类管理
✅ 订单管理（查看/发货/状态维护）
✅ 评论管理（两类线路评论+回复）
✅ 新闻资讯管理、在线客服管理
✅ 购物车/收藏/地址管理、轮播图配置

【技术栈】
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2，前台 Vue+ElementUI 页面，后台 Vue 2.6 + Element UI 2.13 + ECharts 4.6，JDK 1.8，标准 Maven 前后端分离工程（前端均构建好，不用装 Node）。

【数据库】
库名 springbootmt74k，db.sql 自带 15 张表（系统表 3 + 业务表 12：用户/旅游线路/最新线路/线路分类/订单/购物车/地址/收藏/评论×2/在线客服/新闻）+ 示例数据（含云南大理丽江、桂林等示例线路），建库导入即用，ER 图、表结构素材管够。

【运行环境】
JDK 1.8+、MySQL 5.7/8.0，Windows/MacOS 都可以。流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → IDEA 运行主类（或 mvn spring-boot:run）。前台 localhost:8080/springbootmt74k/front/index.html（测试用户"用户1"），后台 .../admin/dist/index.html（管理员 abo），密码见运行必读。
