# 项目事实卡：195 基于SpringBoot的旅游网站的设计与实现

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13）。

## 一、技术栈与版本
- Java 1.8；SpringBoot 2.2.2.RELEASE（pom.xml parent）；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；FastJson 1.2.8；Hutool 4.0.12；commons-lang3 / commons-io
- 前端：后台管理端为 Vue 2.6.10 + Element UI 2.13.0 + axios + ECharts 4.6 的 Vue CLI 工程（工程内含构建好的 dist）；前台为已构建的静态页面（Vue + ElementUI + layui，front/front 目录，含 index.html 与 pages 各页面），**运行均无需 Node 环境**

## 二、功能模块（依据 代码目录 + db.sql 核实；运行必读.txt 为通用模板，功能以代码实际为准）
- **两种角色**：用户（前台）+ 管理员（后台）
- **前台（front/index.html）**：用户注册/登录；首页（轮播图 config 表配置）；旅游线路浏览/搜索/详情；最新线路浏览/详情；线路分类；新闻资讯（列表/详情）；线路收藏；线路评论；购物车（改数量/删除）；下单支付（模拟支付，含余额充值）；我的订单；收货地址管理；在线客服（chat 问答）；个人中心
- **后台（admin/dist/index.html）**：个人中心；用户管理；旅游线路管理（线路名称/分类/封面图/景点/出发地/目的地/交通方式/出行时间/费用包含/行程路线/价格）；最新线路管理；线路分类管理；订单管理（发货/状态维护）；购物车管理；收藏管理；评论管理（旅游线路评论/最新线路评论，含回复）；新闻资讯管理；在线客服管理（回复用户提问）；地址管理；轮播图/全局配置

## 三、数据库
- 库名 `springbootmt74k`，脚本 db.sql 共 **15 张表**：系统表 3 张（users 管理员、token 登录令牌、config 轮播/全局配置）+ 业务表 12 张（yonghu 用户、lvyouxianlu 旅游线路、zuixinxianlu 最新线路、xianlufenlei 线路分类、orders 订单、cart 购物车、address 地址、storeup 收藏、discusslvyouxianlu 线路评论、discusszuixinxianlu 最新线路评论、chat 在线客服、news 新闻资讯）；含建库语句与示例数据（含"云南大理丽江6天5晚""桂林4天3晚"等真实感示例线路），导入即用

## 四、运行
- **端口 8080，上下文路径 /springbootmt74k**（application.yml）
- 数据库：MySQL（jdbc:mysql://127.0.0.1:3306/springbootmt74k），默认账号 root / 123456（application.yml，需改成自己的）
- 启动：IDEA 导入 Maven 工程后运行 `SpringbootSchemaApplication`，或 `mvn spring-boot:run`
- 前台：`http://localhost:8080/springbootmt74k/front/index.html`
- 后台：`http://localhost:8080/springbootmt74k/admin/dist/index.html`（说明文档.txt 指定，推荐谷歌浏览器）
