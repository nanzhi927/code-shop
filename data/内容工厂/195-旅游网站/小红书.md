### 正文（800-1200 字）

选题想做旅游方向但怕"页面太少没东西演示"的同学看过来😭 旅游网站是我见过答辩效果最好的方向之一：前台页面多、业务链完整，演示根本不用凑。今天把我跑通的一套 SpringBoot 旅游网站完整拆给大家，功能、技术栈、数据库、踩过的坑一次讲完。

**为什么推荐这个选题**✅
业务人人都懂（浏览线路→收藏→预订→支付），答辩不用解释"系统是干嘛的"；前台+后台双端，论文功能设计章素材翻倍；自带订单流程，比纯展示型网站好讲得多。

**功能逐条列全**
前台（用户端）👇
✅ 注册登录：用户注册、账号登录
✅ 首页：轮播图（后台可配）+ 线路入口
✅ 旅游线路：列表、搜索、详情页（景点/出发地/目的地/交通/行程路线/费用）
✅ 最新线路：单独栏目，列表+详情
✅ 线路分类：观光/度假/探险/文化/短程等分类浏览
✅ 线路收藏：收藏后个人中心可管理
✅ 线路评论：发表评论、看别人评论
✅ 购物车：加购、改数量、删除
✅ 预订支付：模拟支付流程，支持余额充值
✅ 我的订单：订单列表与状态（未支付/已支付/已完成）
✅ 收货地址管理
✅ 在线客服：直接给管理员发提问、看回复
✅ 个人中心 + 新闻资讯（旅游资讯列表详情）

后台（管理端）👇
✅ 用户管理：用户增删改查
✅ 旅游线路管理 / 最新线路管理：线路全字段维护
✅ 线路分类管理
✅ 订单管理：查看订单、发货、状态维护
✅ 评论管理：两类线路评论的查看与回复
✅ 新闻资讯管理：前台资讯的数据源
✅ 在线客服管理：回复用户提问
✅ 购物车 / 收藏 / 地址管理 + 轮播图配置

重点讲**业务链**：前台浏览线路 → 加购物车/直接预订 → 模拟支付 → 后台订单管理看到这笔单。答辩按这条链现场演示，比背稿稳十倍。

**技术栈与版本**
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2，前台 Vue + ElementUI 静态页面，后台 Vue 2.6 + Element UI 2.13 + ECharts 4.6 管理端，JDK 1.8，前后端分离。工程里前端都是构建好的，运行不用装 Node，学过 SSM 的上手很快。

**数据库**
库名 springbootmt74k，一共 **15 张表**：3 张系统表（管理员/令牌/配置）+ 12 张业务表（用户、旅游线路、最新线路、线路分类、订单、购物车、地址、收藏、线路评论×2、在线客服、新闻）。脚本自带真实感示例数据（云南大理丽江 6 天 5 晚、桂林 4 天 3 晚这种），导入即用，ER 图素材管够。

**这套工程包含什么**
完整 Maven 工程（前台+后台都有）、db.sql 数据库脚本（15 张表+示例数据）、说明文档、运行必读、运行截图 9 张，还**自带论文参考文档、开题报告和 PPT 素材**——都仅供学习参考，自己的论文要自己写✍️
⚠️ 丑话说前面：环境（JDK/MySQL）要自己装，工程里没有录屏演示视频。

**运行门槛**
装 JDK 1.8 + MySQL，建库导入 db.sql，改 application.yml 里的数据库密码，IDEA 里跑主类（或 mvn spring-boot:run）。端口 8080，前台开 `localhost:8080/springbootmt74k/front/index.html`，后台开 `.../admin/dist/index.html`，管理员账号 abo，前台测试用户"用户1"，密码见运行必读。

**我踩过的坑**
1. 前后台是两个地址，中间的 /springbootmt74k 路径别漏，直接开 8080 会 404；
2. 数据库密码默认 123456，和你自己的不一样一定报连接失败，先改配置再启动；
3. 前台要登录后才能预订收藏，答辩演示记得先注册/登录一个账号。

**适合谁**
✅ 技术栈匹配（Java/SSM/SpringBoot 学过其一）的
✅ 选题想做旅游/电商类网站、要完整订单流程的
✅ 答辩想靠页面和业务链演示加分的
❌ 想不写论文直接交差的——参考文档只是参考，绕不过去

**答辩建议**
按"前台业务链演示（浏览→预订→支付）→ 后台订单管理 → 15 张表怎么设计"这条线准备，页面多就是天然优势，每个功能都有截图可用。
