### 正文（答疑帖体）

每天私信被问得多的就这几个问题，干脆整理成一篇，诚实回答，看完了再决定要不要来问👇

**Q1：能跑吗？跑不起来怎么办**
A：我自己电脑实测跑通过才发的，有真机演示视频，可以先看再决定。万一你环境装不明白，把报错截图发我，我可以远程帮你看。别自己卡三天。

**Q2：有论文吗？**
A：**没有**。只有源码 + 数据库脚本（admin1.sql，44 张表）+ 运行必读 + 运行截图 + 真机演示视频。论文要自己写，技术实现章节怎么写、答辩怎么讲可以问我，但论文本身我不能提供。

**Q3：能改吗？能加功能吗？**
A：能。这套是 SpringBoot 2.0.3 + MyBatis + Shiro + Thymeleaf 的标准工程，二次开发友好。改题目、加功能、换前端这类需求可以私信说下你的要求，我先帮你评估工作量和可行性，再给你方案——评估本身可以先聊。

**Q4：环境不会装怎么办？**
A：JDK 1.8 / Maven / MySQL / Redis，步骤我写过保姆级教程（含 3 个高频报错）。实在不行，远程部署这块可以聊（增值服务详见定价说明，引用 00-通用素材/07）。

**Q5：多少钱？能便宜吗？**
A：分渠道定价不同（低价引流款/完整版/增值服务），具体引用 00-通用素材/07，私信你说下需求我给你对一下，不在这里发价格。

**Q6：为什么相信你，是不是骗子？**
A：正常顾虑，不用先付全款——可以先看真机演示视频，可以先小额，跑通了再说。我不删评论不吵架，有问题评论区随便问。

**Q7：答辩怎么办，能帮我过吗？**
A：我能做的是**技术讲解和答辩准备**：这个项目答辩会被问什么、技术点怎么讲、演示怎么彩排，这些我可以梳理给你。我不能也不会替你答辩，毕设得你自己上——准备得越早越稳。

**Q8：这是什么技术栈？我学过 SSM 换得动吗？**
A：SpringBoot 2.0.3、MyBatis、Shiro、Thymeleaf、Activiti 5.22 工作流、Redis/Ehcache 缓存、Druid 连接池。有 SSM 基础上手很快，SpringBoot 本身就是简化配置那一套。

**Q9：前台能改成我自己的公司/主题吗？**
A：能。前台 5 个栏目的内容都在后台配（文章、产品、轮播图），不用改代码就能换内容；要换风格、换栏目结构属于二次开发，可以聊需求。

**Q10：数据库要自己建吗？**
A：不用设计。脚本自带 44 张表和示例数据，建库导脚本即可（utf8 字符集）。表结构怎么讲、ER 图怎么画我写过文章可以翻。

**Q11：能在 Mac 上跑吗？**
A：支持 Windows / MacOS，JDK 1.8 + MySQL + Redis 装好就行。

**Q12：演示视频端口和你写的不一样？**
A：项目默认端口 80；演示视频里若显示 18080，是录制时改过的，以运行说明为准——这不是 bug，如实说明。

**Q13：代码是原创吗？**
A：基于开源脚手架（bootdo）二次定制开发，Gitee/GitHub 上开源学习版会注明"学习交流用"。学习使用没问题，我不拿"从零手写"骗你。

**Q14：买了之后有售后吗？**
A：跑不起来远程帮看、报错帮分析这些都有（范围和方式见定价说明）。长期的技术问题也可以问，我看到就回。

**Q15：后续还能问问题吗？**
A：能。选题、环境、论文技术实现的思路、答辩准备，都可以问。但丑话重复一遍：论文没有、答辩要自己上，这两条答应不了😄

有问题评论区补，这篇会持续更新。想评估自己需求的，私信说下：专业、定题没定、卡在哪一步～
