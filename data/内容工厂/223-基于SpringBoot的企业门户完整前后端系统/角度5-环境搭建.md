### 一、图文教程（小红书/CSDN 体）

拿到源码跑不起来，是毕设季我被问得更多的问题，没有之一😭 其实 90% 卡壳都是环境问题。拿我手上这套 SpringBoot 企业门户做例子，完整跑一遍：

**第 0 步：先确认你有什么**
源码工程 + admin1.sql 数据库脚本 + 运行必读.txt。丑话说前面：**论文是没有的**，论文要自己写。

**第 1 步：装基础环境**
- JDK 1.8（这套就认 1.8，别装太高的版本，装完 `java -version` 验证）
- Maven（IDEA 自带的也行）
- MySQL（5.5 / 5.7 / 8.0 都可以）
- Redis（默认本机 6379，没装的话装一个）

**第 2 步：导入数据库**
新建库，字符集选 utf8，把 admin1.sql 导进去。
```
create database admin1 default character set utf8;
use admin1;
source 你的路径/admin1.sql;
```
导完应该能看到 44 张表（含工作流表和系统表）。少表 = 脚本没导完，重来。

**第 3 步：改配置**
打开 `src/main/resources/application.yml`：
- 改数据库连接：库名、用户名、密码，改成你自己的
- 端口：默认是 80，被占用就改，比如 8080
- Redis 配置确认指向本机 6379

**第 4 步：启动**
```
mvn spring-boot:run
```
或者打包跑：
```
mvn clean package -DskipTests
java -jar target/bootdo-2.0.0.jar
```
看到启动完成的日志就 OK。前台访问 `/home`，后台 `/login`（管理员账号见运行说明）。

**3 个高频报错（对号入座）**

1. **数据库连接失败（Access denied / Communications link failure）**：九成是 application.yml 里密码/库名没改对，或者 MySQL 服务没启动。先在命令行用同样的账号密码 `mysql -u xxx -p` 能不能登进去验证。
2. **端口被占用（Port 80 was already in use）**：80 端口容易被其他程序占着，把 server.port 改成 8080 之类的就行；或者找到占用进程关掉。
3. **Maven 依赖下载不动 / 工程报红**：换国内镜像源（aliyun 的 maven 镜像），删掉本地仓库里下载一半的目录重新 update；IDEA 导入后记得等依赖全部下完再看报错。（具体报错截图可发我看，细节因环境而异【待核实】）
