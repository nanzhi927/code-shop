# 项目事实卡：223 基于SpringBoot的企业门户完整前后端系统

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-12）。

## 一、技术栈与版本
- Java 1.8；SpringBoot 2.0.3.RELEASE；MyBatis 3.4.4（含 MyBatis-Plus starter）；Apache Shiro；Thymeleaf；Druid 1.0.28；Activiti 5.22.0；Ehcache + Redis；前端 jQuery / bootstrapTable / layer / summernote / jsTree

## 二、功能模块
- **前台 5 栏目**：首页、关于我们、产品展示、新闻中心、联系我们
- **后台**：文件管理；用户/角色/菜单/部门管理；在线用户/系统日志/运行监控；文章信息管理；产品图片管理；首页轮播图与轮播图类型管理

## 三、数据库
- 库名 `admin1`，脚本共 **44 张表**（Activiti 工作流表 25 张 + 系统表 11 张 + 业务表等），含 DROP/CREATE 与示例数据，导入即用。介绍时表述为"44 张表（含工作流与系统表）"，**不声称全部为业务表**。

## 四、运行
- **默认端口 80**（`src/main/resources/application.yml` 的 `server.port`；演示视频中出现的 18080 系录制时修改，非原始值）
- 启动：`mvn spring-boot:run` 或 `mvn clean package -DskipTests && java -jar target/bootdo-2.0.0.jar`
- 环境：JDK 1.8+，MySQL 5.5/5.7/8.0，Windows/MacOS；Redis 默认本机 6379
- 前台 `/home`，后台 `/login` → `/index`
