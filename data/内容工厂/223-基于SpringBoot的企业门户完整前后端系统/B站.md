### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 企业门户系统：前台是标准企业官网，后台是完整管理端，一个工程里搞定。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.0.3 + MyBatis 3.4.4（含 MyBatis-Plus）+ Apache Shiro + Thymeleaf + Druid 连接池 + Activiti 5.22 工作流 + Ehcache/Redis 缓存，JDK 1.8，标准 Maven 工程，前端 jQuery/bootstrapTable/layer/summernote/jsTree。基于开源脚手架（bootdo）二次开发，供学习交流用。

【完整功能清单】
前台 5 栏目：首页（轮播大图+栏目入口）、关于我们、产品展示（列表+详情）、新闻中心（列表+详情）、联系我们——内容全部在后台配置，前台刷新即生效，不用改代码。
后台 9 组功能：
- 用户管理 / 角色管理 / 菜单管理 / 部门管理（Shiro 三级权限：用户-角色-菜单，控制到按钮级）
- 文章信息管理（前台新闻数据源）
- 产品图片管理（前台产品数据源）
- 首页轮播图管理 / 轮播图类型管理
- 文件管理（图片附件统一管理）
- 在线用户 / 系统日志 / 运行监控

【数据库说明】
库名 admin1，脚本自带 44 张表（Activiti 工作流表 25 张 + sys_ 系统表 11 张 + 门户业务表等）+ 示例数据，建库导脚本即可用。管理员账号 admin、测试账号 test（密码见运行说明）。

【运行环境】
JDK 1.8+、Maven、MySQL 5.5/5.7/8.0、Redis（本机 6379）；Windows/MacOS。启动：mvn spring-boot:run，或 mvn clean package -DskipTests 后 java -jar target/bootdo-2.0.0.jar。前台访问 /home，后台 /login，默认端口 80。
⚠️ 说明：演示视频里端口若显示 18080，是录制时改过的，项目默认端口是 80，以运行说明为准。
