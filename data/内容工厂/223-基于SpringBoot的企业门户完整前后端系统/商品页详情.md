**项目简介**

基于 SpringBoot 2.0.3 的企业门户完整前后端系统：前台是标准企业官网，后台是完整管理端，同一个 Maven 工程完成。基于开源脚手架（bootdo）二次开发，供学习交流使用。管理员账号 admin、测试账号 test（密码见运行必读）。

**功能模块（分组逐条）**

前台（企业官网，5 栏目）：
✅ 首页：轮播大图+栏目入口，轮播图在后台配
✅ 关于我们：公司介绍页，内容后台可编辑
✅ 产品展示：产品列表+详情页
✅ 新闻中心：文章列表+详情页，后台发文即更新
✅ 联系我们：联系方式展示页

后台（管理端，9 组功能）：
✅ 用户管理：用户增删改查、分配角色
✅ 角色管理：角色维护、菜单权限分配
✅ 菜单管理：树形菜单，控制页面级权限
✅ 部门管理：按部门组织人员
✅ 文章信息管理：前台新闻中心的数据源，富文本编辑
✅ 产品图片管理：前台产品展示的数据源
✅ 首页轮播图管理+轮播图类型管理：首页大图及分类配置
✅ 文件管理：上传的图片、附件统一管理
✅ 在线用户/系统日志/运行监控：操作留痕审计、服务器状态

权限体系：Apache Shiro 实现 RBAC，用户-角色-菜单三级，控制到按钮级——答辩讲权限就有现成演示。

**技术架构与版本**

Java 1.8；SpringBoot 2.0.3.RELEASE；MyBatis 3.4.4（含 MyBatis-Plus starter）；Apache Shiro；Thymeleaf；Druid 1.0.28；Activiti 5.22.0 工作流；Ehcache + Redis 缓存；前端 jQuery/bootstrapTable/layer/summernote/jsTree；数据库 MySQL 5.5/5.7/8.0。学过 SSM 的上手很快。

**数据库说明**

库名 admin1，共 44 张表：Activiti 工作流标准表 25 张（引擎自带，无需手工设计）、sys_ 系统表 11 张（用户/角色/菜单/部门/日志等，经典 RBAC）、门户业务表若干（文章/产品/轮播图等）。脚本含 DROP/CREATE 与示例数据，重复导入不冲突。

**运行环境**

JDK 1.8+、Maven、MySQL 5.5/5.7/8.0、Redis（本机 6379）；Windows/MacOS 均可。启动流程：建库（utf8）→ 导入 admin1.sql → 改 application.yml 数据库密码 → `mvn spring-boot:run`（或 `mvn clean package -DskipTests` 后 `java -jar target/bootdo-2.0.0.jar`）。前台 /home，后台 /login，默认端口 80（被占用可改 server.port）。
