### 正文（800-1200 字）

开题被卡的同学看过来：交通类选题里，车辆管理系统是那种"业务一听就懂、技术点又够讲"的安全牌😭 今天把我手上这套 SpringBoot 车辆管理系统完整拆开：功能、技术栈、数据库、我踩过的坑，一次讲完，开题和答辩都能照着准备。工程、脚本、运行截图都是齐的，照运行必读一步步来就行。

**为什么推荐这个选题**✅
业务零解释成本（管车辆、记保养，老师一听就懂）；模块天然工整（一辆车配四类登记，论文每章都有东西写）；工作量扎实但不失控。想避开烂大街电商、图书方向的同学，可以考虑。

**功能逐条列全**（前后端分离：SpringBoot 接口 + Vue 管理端）
登录角色两种：管理员、员工（员工还能自己注册）👇
✅ 首页：统计图表，数据实时汇总
✅ 车辆管理：车辆名称、类型、车牌号、所属车主，增删改查分页全有
✅ 保养登记管理：保养名称、类型、时间、详情，登记即留档
✅ 事故登记管理：事故类型、责任方（我方/他方）、详情记录
✅ 维修登记管理：维修类型、维修记录全流程
✅ 违章登记管理：违章类型、违章记录
✅ 用户管理：车主档案（姓名、电话、身份证、准驾车型、驾驶证号）
✅ 员工管理：员工信息与账号维护
✅ 基础数据管理：保养类型/车辆类型/事故类型/维修类型/违章类型/准驾车型全部字典配置，改下拉选项不用动代码
✅ 个人中心 + 修改密码

**技术栈与版本**
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Vue 管理端（element-ui），JDK 1.8，Maven 工程。鉴权是自定义 Token 拦截器——答辩讲"登录态怎么维持"就有现成答案，比背概念强。

**数据库**
库名 cheliangguanli，**11 张表**：业务表 8 张（车辆、四类登记、车主档案、员工、字典）+ 系统表 3 张（管理员、token、配置）。脚本自带建库语句和示例数据，导入即用。表不多但关系清晰，ER 图那章画起来毫无压力。

**这套工程包含什么**
完整 Maven 工程（Vue 代码工程和打包版都在里面）、db.sql 数据库脚本、运行必读、运行截图 13 张、论文截图 3 张，还有一份 Word 论文参考和一份答辩 PPT。
⚠️ 丑话说前面：论文和 PPT 是按 SSM 技术栈写的，工程实际是 SpringBoot，技术表述要自己调整着用；环境（JDK/MySQL）也要自己装；演示视频没有。

**运行门槛**
装 JDK 1.8 + Maven + MySQL 5.7 以上，导 db.sql（脚本自带建库），改 application.yml 里的数据库密码，`mvn spring-boot:run` 启动。端口 8080，访问路径带 /cheliangguanli 前缀。管理员 admin/admin，员工 a1、a2、a3/123456。

**我踩过的坑**

2. 上传图片文件名不能带中文，带了会保存失败；
3. 先跑通再动论文，尤其是技术表述要和工程对齐（SSM 还是 SpringBoot 别写混）。

**适合谁**
✅ 学过 Java/SSM 想上手前后端分离的
✅ 时间紧、需要一套结构清晰的完整工程做参考的
✅ 答辩要讲"前后端分离怎么做""登录鉴权怎么实现"的

**答辩建议**
按"前后端分离架构（Vue 调 REST 接口）→ 11 张表的构成（8 业务 + 3 系统）→ 字典驱动的基础数据配置"这条线讲，比背稿稳。
