### 一、视频简介（600-1000 字）

这期视频完整讲解一套 SpringBoot 车辆管理系统：后端 SpringBoot 提供 REST 接口，前端 Vue 管理端，前后端分离架构，围绕"车辆 + 保养/事故/维修/违章四类登记"的业务闭环。工程、数据库脚本、运行截图齐全，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Vue 管理端（element-ui），JDK 1.8，标准 Maven 工程。鉴权为自定义 Token 拦截器（token 表存登录态，拦截器统一校验）。两种登录角色：管理员、员工（员工支持注册）。

【完整功能清单】
- 首页：统计图表，分组汇总数据
- 车辆管理：车辆名称、类型、车牌号、所属车主，增删改查分页
- 保养登记 / 事故登记 / 维修登记 / 违章登记：四类登记模块，全流程留档
- 用户管理：车主档案（电话、身份证、准驾车型、驾驶证号）
- 员工管理：员工信息与账号维护
- 基础数据管理：保养/车辆/事故/维修/违章类型、准驾车型等字典全部后台可配，改下拉选项不改代码
- 个人中心、修改密码

【数据库说明】
库名 cheliangguanli，共 11 张表：业务表 8 张（车辆、四类登记、车主档案、员工、字典）+ 系统表 3 张（管理员、token、配置）。脚本自带建库语句与示例数据（字典 35 条、车辆 12 条等），导入即用，ER 图素材够画。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7 以上；Windows/macOS 均可。启动：导 db.sql → 改 application.yml 数据库密码 → mvn spring-boot:run。端口 8080，访问地址带 /cheliangguanli 前缀（完整地址见运行必读）。管理员 admin/admin，员工 a1、a2、a3/123456。注意：上传图片文件名不能带中文。
