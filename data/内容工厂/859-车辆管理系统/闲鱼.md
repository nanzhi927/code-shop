### 商品描述（600-1000 字）

【项目定位】
前后端分离的 SpringBoot 车辆管理系统：后端 SpringBoot 提供 REST 接口，前端 Vue 管理端（element-ui），围绕"车辆 + 保养/事故/维修/违章四类登记"做业务闭环，附运行截图 13 张，功能对照看得见。

【功能清单·两种登录角色】
管理员（admin）：
✅ 首页统计图表（数据分组汇总）
✅ 车辆管理：名称、类型、车牌号、所属车主
✅ 保养登记 / 事故登记 / 维修登记 / 违章登记：四类登记全流程留档
✅ 用户管理：车主档案（电话、身份证、准驾车型、驾驶证号）
✅ 员工管理：员工信息与账号维护
✅ 基础数据管理：保养/车辆/事故/维修/违章类型、准驾车型等字典全部可配置，改下拉选项不用动代码
员工（a1/a2/a3，支持自行注册）：车辆与四类登记的日常操作。

【技术栈】
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Vue 管理端，JDK 1.8，标准 Maven 工程；鉴权为自定义 Token 拦截器（登录态维持的现成讲解素材）。

【数据库】
库名 cheliangguanli，11 张表（业务表 8：车辆、四类登记、车主档案、员工、字典；系统表 3：管理员、token、配置），脚本自带建库语句与示例数据（字典 35 条、车辆 12 条等），导入即用，ER 图素材够画。

【交付内容】
📦 完整 Maven 源码工程（含 Vue 前端代码工程与打包版）
📦 数据库脚本 db.sql（11 张表+示例数据）
📦 论文参考文档（Word 版）+ 答辩 PPT
📦 运行必读.txt + 说明文档.txt
📦 运行截图 13 张 + 论文截图 3 张
⚠️ 不含演示视频；论文与 PPT 按 SSM 技术栈表述撰写，工程实际为 SpringBoot，技术章节需自行调整后使用，介意慎拍。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7 以上，Windows/macOS 都可以。流程：导 db.sql（自带建库）→ 改 application.yml 数据库密码 → mvn spring-boot:run。端口 8080，访问地址带 /cheliangguanli 前缀（运行必读里有完整地址）。注意：上传图片文件名不能带中文。
