### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 房屋租赁系统：管理员、用户、房主三个角色，覆盖"找房→预约→签约→报修→评价"全流程。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis（starter 2.1.1）+ MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + FastJSON + Hutool，JDK 1.8；后台 Vue + Element-UI（带构建产物），前台静态页（layui/Element-UI）。标准 Maven 工程，供学习交流用。

【完整功能清单】
前台 6 栏目：首页、房屋信息（月租金/押金/面积/朝向/小区/设施全字段）、我要当房主（用户提交房源申请）、公告信息、留言反馈、个人中心。
后台三角色：
- 管理员 13 组：用户/房主/房屋类型/房屋信息/预约看房/合同信息/房屋报修/维修处理/房屋评价/我要当房主审核/留言板/系统管理/个人中心
- 用户端 8 项：预约看房、合同信息、房屋报修、维修处理跟踪、房屋评价、我要当房主申请、我的收藏、个人中心
- 房主端 7 项：管理房源、审核预约、管理合同、处理报修、跟进维修、回复评价、个人中心

【数据库说明】
库名 springboot08hr3，脚本自带 18 张表（系统支撑 3 张 + 公告留言 2 张 + 租赁业务 13 张）+ 示例数据，建库导脚本即可用。管理员账号 abo；演示数据里有房主账号"1"、用户账号"2"（密码同账号）。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7+；Windows/MacOS。启动：IDEA 运行主类 SpringbootSchemaApplication，或 mvn spring-boot:run。默认端口 8080；前台 /front/index.html，后台 /admin/dist/index.html。
⚠️ 说明：改了后台 Vue 源码要重新 build 才生效，dist 是构建产物。
