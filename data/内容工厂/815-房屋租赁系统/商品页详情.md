**项目简介**

基于 SpringBoot 2.2.2 的房屋租赁完整前后端系统：前台 6 栏目 + 三角色后台，同一个 Maven 工程完成。管理员账号 abo；数据库演示数据里含房主与用户演示账号，可直接登录演示。

**功能模块（分组逐条）**

前台（6 栏目）：
✅ 首页：核心内容与轮播展示
✅ 房屋信息：可租房源列表+详情（月租价格、押金、租赁方式、面积、朝向楼层、小区、设施全字段）
✅ 我要当房主：用户提交房源/房主申请
✅ 公告信息：系统公告展示
✅ 留言反馈：留言板互动
✅ 个人中心：资料与密码管理

后台（管理员 13 组）：
✅ 用户管理 / 房主管理：两类账号维护
✅ 房屋类型管理 / 房屋信息管理：字典与房源增删改查
✅ 预约看房管理：预约审核、取消处理
✅ 合同信息管理：合同生成/终止（月租、押金、租用月数、合同金额、支付状态）
✅ 房屋报修管理 / 维修处理管理：报修单处理 + 维修进度记录（维修中/已完成）
✅ 房屋评价管理：评价查看与回复
✅ 我要当房主管理：申请审核，通过后账号角色升级
✅ 留言板管理 / 系统管理（轮播图、公告）/ 个人中心

用户端 8 项：预约看房、合同信息、房屋报修、维修处理跟踪、房屋评价、我要当房主申请、我的收藏、个人中心。
房主端 7 项：管理自己的房源、审核预约、管理合同、处理报修、跟进维修、回复评价、个人中心。

权限体系：Apache Shiro 1.3.2 三角色分权；"我要当房主"审核通过后功能菜单随之变化——权限跟随业务状态流转，答辩讲权限设计的现成案例。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis（starter 2.1.1）+ MyBatis-Plus 2.3；Apache Shiro 1.3.2；FastJSON 1.2.8；Hutool 4.0.12；后台 Vue + Element-UI（含 dist 构建产物），前台静态页（layui/Element-UI/TinyMCE）；数据库 MySQL 5.7+。主启动类 com.SpringbootSchemaApplication。学过 SSM 的上手很快。

**数据库说明**

库名 springboot08hr3，共 18 张表：系统支撑 3 张（config/token/users）、公告留言 2 张（news/messages）、租赁业务 13 张（房屋信息、房屋类型、房主、用户、预约看房、合同信息、房屋报修、维修处理、房屋评价、我要当房主、评论×2、收藏）。脚本含 DROP/CREATE 与示例数据，重复导入不冲突。

**运行环境**

JDK 1.8+、Maven、MySQL 5.7+；Windows/MacOS 均可，IDEA/Eclipse 均可。启动流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → 运行主类或 `mvn spring-boot:run`。默认端口 8080；前台 /front/index.html，后台 /admin/dist/index.html。
