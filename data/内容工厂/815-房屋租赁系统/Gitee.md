# 房屋租赁系统-SpringBoot（毕设学习版）

基于 SpringBoot 的房屋租赁完整前后端系统**教学版**：**管理员 / 用户 / 房主**三种角色，覆盖"浏览房源 → 预约看房 → 签约合同 → 报修维修 → 房屋评价"全流程闭环，数据库 18 张表导入即用，适合毕业设计、课程设计的学习参考与技术交流。

> 本仓库为教学版，供学习交流使用；完整版（含全部资料、运行截图、PPT、运行说明与答疑）获取方式见文末引导。

## 项目简介

- **前台**：6 个栏目——首页、房屋信息、我要当房主、公告信息、留言反馈、个人中心。房源字段完整（月租金、押金、租赁方式、面积、朝向楼层、小区、设施等）。
- **后台**：三角色分权——管理员 13 组功能（用户/房主/房屋类型/房屋信息/预约看房/合同信息/房屋报修/维修处理/房屋评价/我要当房主审核/留言板/系统管理）；用户端 8 项；房主端 7 项。
- **数据库**：MySQL，库名 `springboot08hr3`，18 张表（系统支撑 3 + 公告留言 2 + 租赁业务 13），脚本自带建表语句与示例数据，导入即用。
- **工程**：标准 Maven 结构，JDK 1.8，SpringBoot 2.2.2.RELEASE，主启动类 `com.SpringbootSchemaApplication`。

## 数据库设计

库名 `springboot08hr3`，共 18 张表，按用途分三类：

| 分类 | 数量 | 说明 |
|---|---|---|
| 系统支撑表 | 3 张 | `config`（参数配置）、`token`（登录令牌）、`users`（管理员账号） |
| 公告与留言 | 2 张 | `news`（公告）、`messages`（留言板） |
| 租赁业务表 | 13 张 | 房屋信息 `fangwuxinxi`、房屋类型 `fangwuleixing`、房主 `fangzhu`、用户 `yonghu`、预约看房 `yuyuekanfang`、合同信息 `hetongxinxi`、房屋报修 `fangwubaoxiu`、维修处理 `weixiuchuli`、房屋评价 `fangwupingjia`、我要当房主 `woyaodangfangzhu`、评论 `discussfangwuxinxi` / `discusswoyaodangfangzhu`、收藏 `storeup` |

脚本包含 DROP/CREATE 语句与示例数据（含真实演示房源"新记家园605房"及其预约、合同、报修、评价记录），重复导入不冲突。

主要表设计说明：
- `fangwuxinxi`（房屋信息）：展示维度（名称/类型/图片/详情）+ 交易维度（月租金/押金/租赁方式）+ 位置维度（小区/详细地址/朝向楼层）+ 归属维度（房主账号/姓名），一张表四个维度，适合论文按维度分析；
- `hetongxinxi`（合同信息）：合同编号、月租金、租用月数、租用金额、押金、合同金额、生效日、有效期至、支付状态（ispay），金额字段完整；
- `fangwubaoxiu` / `weixiuchuli`：报修（需求）与维修处理（执行记录）分离，进度字段为状态机思路（维修中/已完成）。

ER 图建议按三层绘制：权限层（用户/房主/管理员与申请审核关系）、交易层（预约→合同→支付状态）、服务层（报修→维修处理→评价）。

## 快速开始

第 1 步：导入数据库

```sql
create database springboot08hr3 default character set utf8;
use springboot08hr3;
source 你的路径/db.sql;
```

或命令行直接导入：

```bash
mysql -u用户名 -p springboot08hr3 < db.sql
```

导入后应能看到 18 张表；表数量不足说明脚本未导完，重新导入即可。

第 2 步：修改配置。打开 `src/main/resources/application.yml`：
- 数据库连接：`jdbc:mysql://127.0.0.1:3306/springboot08hr3`，username/password 改成你自己的（工程默认 root/123456）；
- 端口：默认 8080，被占用可修改 `server.port`。

第 3 步：启动

```bash
mvn spring-boot:run
```

或 IDEA 中直接运行主类 `com.SpringbootSchemaApplication`。

第 4 步：访问验证
- 前台：`http://localhost:8080/springboot08hr3/front/index.html`
- 后台登录：`http://localhost:8080/springboot08hr3/admin/dist/index.html`

管理员账号见运行说明（工程内置演示账号与数据库演示数据，登录后请及时修改密码）。

## 常见问题（FAQ）

**Q1：启动报数据库连接失败（Access denied / Communications link failure）？**
九成是 application.yml 里数据库密码/库名没改对，或 MySQL 服务未启动。先在命令行用同样账号密码登录 MySQL 验证。

**Q2：报端口被占用（Port 8080 was already in use）？**
把 `server.port` 改成其他未占用端口，或关闭占用 8080 的进程。

**Q3：改了后台页面没生效？**
后台是 Vue 工程，`dist` 是构建产物；修改 `src` 下源码后需要重新 build（admin 目录内有 package.json 与构建脚本）。

**Q4：Maven 依赖下载慢或工程报红？**
配置国内镜像源（如阿里云 Maven 镜像），删除本地仓库中下载不完整的目录后重新 update；IDEA 导入后等待依赖全部下载完成再看报错。

**Q5：上传的图片显示不出来？**
图片路径带 context-path 前缀（/springboot08hr3/upload/...），修改端口或做反向代理时要整体核对路径；上传文件名避免中文。

**Q6：18 张表分别是干什么的？**
见"数据库设计"一节的三分类与表名清单；导完表数量不足 18 说明脚本没导完。

**Q7：三种角色的账号怎么来的？**
管理员见运行说明；数据库脚本自带演示数据（含房主与用户演示账号，密码同账号或 123456），登录后建议改密。

**Q8：这个项目能用作毕业设计吗？**
可以作学习参考。建议在其上做自己的业务改造，答辩时如实说明来源，能讲清原理比"从零手写"的说法更稳。

**Q9：有论文或开题报告吗？**
没有论文文档（工程包内仅论文截图），仓库只有源码与数据库脚本。论文请自己撰写，技术实现思路可以交流。

**Q10：支持 MySQL 8 吗？**
说明文档标注 MySQL 5.7 及以上可用；MySQL 8 需注意驱动与时区配置（application.yml 已带 serverTimezone 参数）。
