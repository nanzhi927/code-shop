# 项目事实卡：815 房屋租赁系统

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13，实际读取源码目录 D:\从戎网站源码\springboot源码\1\springboot008房屋租赁系统--论文）。

## 一、技术栈与版本
- Java 1.8；SpringBoot 2.2.2.RELEASE（spring-boot-starter-parent 2.2.2）；MyBatis（mybatis-spring-boot-starter 2.1.1）+ MyBatis-Plus 2.3；Apache Shiro 1.3.2；FastJSON 1.2.8；Hutool 4.0.12；百度 AI SDK（java-sdk 4.4.1）；mysql-connector-java（版本随 parent 管理）
- 前端：后台为 Vue + Element-UI（含 dist 构建产物，源码在 src/main/resources/admin/admin）；前台为静态 HTML 页（src/main/resources/front/front，用 layui / Element-UI / TinyMCE 富文本）
- 工程为标准 Maven 结构，主启动类 `com.SpringbootSchemaApplication`

## 二、功能模块
- **前台 6 栏目**：首页、房屋信息、我要当房主（用户提交房源）、公告信息、留言反馈、个人中心
- **后台（管理员，13 组）**：个人中心；用户管理；房主管理；房屋类型管理；房屋信息管理；预约看房管理；合同信息管理；房屋报修管理；维修处理管理；房屋评价管理；我要当房主管理；留言板管理；系统管理（轮播图/公告等）
- **用户端（8 项）**：个人中心；预约看房；合同信息；房屋报修；维修处理；房屋评价；我要当房主（申请成为房主）；我的收藏
- **房主端（7 项）**：个人中心；房屋信息管理；预约看房管理；合同信息管理；房屋报修管理；维修处理管理；房屋评价管理
- **业务主线**：浏览房源 → 预约看房（房主/管理员审核）→ 生成合同（月租/押金/租用月数/合同金额，含已支付状态）→ 入住后报修 → 维修处理（维修进度：维修中/已完成）→ 房屋评价；用户可申请"我要当房主"发布自己的房源

## 三、数据库
- 库名 `springboot08hr3`，脚本 db.sql 共 **18 张表**（系统支撑表 3：config/token/users；公告与留言 2：news/messages；租赁业务表 13：房屋信息、房屋类型、房主、用户、预约看房、合同信息、房屋报修、维修处理、房屋评价、我要当房主、房屋信息评论、我要当房主评论、收藏）
- 脚本含 DROP/CREATE 与示例数据（含"新记家园605房"等真实演示数据），导入即用
