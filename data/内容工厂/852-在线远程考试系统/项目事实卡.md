# 项目事实卡：852 基于Spring Boot在线远程考试系统的设计与实现

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13）。

## 一、技术栈与版本（pom.xml 实测）
- Java 1.8；SpringBoot **2.2.2.RELEASE**（spring-boot-starter-parent）
- MyBatis：mybatis-spring-boot-starter **2.1.1**；MyBatis-Plus **2.3**（mybatisplus-spring-boot-starter 1.0.5）
- Apache Shiro **1.3.2**（shiro-spring）；Thymeleaf（spring-boot-starter-thymeleaf）；devtools 热部署
- 工具库：fastjson（1.2.8）、hutool-all 4.0.12、commons-lang3 3.0、commons-io 2.5、protobuf-java 3.10.0、validation-api 2.0.1
- 前端：Vue 2.6 + Element UI + axios（后台 admin 为 Vue 工程，dist 已打包；前台 front 用 elementui 静态资源）
- 标准后端分层：controller / dao / entity / service / model(enums) / thread / interceptor / annotation（IgnoreAuth、LoginUser）

## 二、功能模块（Controller + 运行必读 双重核实）
- **角色 3 种**：管理员、老师、用户（学生）；前后台分离
- **前台 4 个栏目**：首页（核心内容与功能入口）、试卷列表（可参与的考试试卷）、公告（考试通知等）、个人中心（资料、成绩）
- **后台（用户/学生）**：个人中心；公告管理（查看）；考试管理（参与已发布考试）
- **后台（管理员）8 组**：个人中心；公告类型管理；公告管理；用户管理；老师管理；试卷管理；考试管理；轮播图信息
- **后台（老师）5 组**：个人中心；公告管理；用户管理（学生用户维护）；试卷管理；考试管理
- Controller 清单（13 个）：Common、Config、Dictionary、Exampaper、Examquestion、Examrecord、Examredetails、Examrewrongquestion、File、Gonggao、Laoshi、Users、Yonghu
- **考试核心能力（db.sql + 实体字段核实）**：
  - 试卷表 exampaper：试卷名称、考试时长（分钟）、试卷总分数、试卷状态、逻辑删除
  - 试题表 examquestion：所属试卷外键、试题名称、选项（JSON 字符串）、分值、正确答案、**答案解析**、试题类型（示例数据含单选/多选/判断/填空 4 类）、排序
  - 考试记录 examrecord（含考试编号）、答题详情 examredetails、错题表 examrewrongquestion（**支持成绩记录与错题回顾**）

## 三、数据库（db.sql 实测）
- 库名 `zaixianyuanchengkaoshixitong`，脚本共 **12 张表**：
  - 业务表 7：exampaper（试卷）、examquestion（试题）、examrecord（考试记录）、examredetails（答题详情）、examrewrongquestion（错题）、gonggao（公告）、laoshi（老师）
  - 系统表 5：config（配置/轮播图）、dictionary（字典）、token（令牌）、users（管理员）、yonghu（用户）
- 含 DROP/CREATE 与示例数据（含 2 套示例试卷、8 道示例试题），导入即用
