# 在线考试系统-SpringBoot（毕设学习版）

基于 SpringBoot 的在线远程考试系统**教学版**：管理员/老师/用户（学生）三种角色，包含**前台考试端**（4 栏目）与**后台管理端**（老师端 5 组 + 管理员端 8 组功能），支持 4 种题型、限时答题、自动判分与错题本，数据库 12 张表导入即用，适合毕业设计、课程设计的学习参考与技术交流。

> 本仓库为教学版，供学习交流使用；完整版（含论文参考文档、演示 PPT、任务书、开题报告、运行截图与答疑）获取方式见文末引导。

## 项目简介

- **前台**：考试端 4 栏目——首页（核心内容与功能入口）、试卷列表（可参与的考试）、公告（考试通知）、个人中心（资料与成绩）。
- **后台（学生端）**：个人中心、公告查看、考试管理（参与已发布考试）。
- **后台（老师端）**：个人中心、公告管理、用户管理（学生维护）、试卷管理、考试管理。
- **后台（管理员端）**：个人中心、公告类型管理、公告管理、用户管理、老师管理、试卷管理、考试管理、轮播图信息。
- **考试全流程闭环**：老师出题（4 种题型）→ 组卷（设时长/总分/状态）→ 学生限时答题 → 自动判分 → 考试记录 + 答题详情 + 错题本。
- **数据库**：MySQL，库名 `zaixianyuanchengkaoshixitong`，12 张表（业务表 7 + 系统表 5），含 2 套示例试卷与 8 道示例试题，导入即用。
- **工程**：标准 Maven 结构，JDK 1.8，SpringBoot 2.2.2.RELEASE。

## 考试核心功能

- **4 种题型**：单选、多选、判断、填空（db.sql 示例数据实测齐全）；
- **限时考试**：试卷设置考试时长（分钟），答题页面计时；
- **自动判分**：提交答卷后由后端逐题比对正确答案判分——单选/判断直接比对，多选全对才得分，填空比对标准答案；正确答案不下发到答题页面，判分安全可靠；
- **成绩记录**：考试记录带考试编号，后台可统一查询；
- **答题详情**：逐题答案落库，可回溯每一次考试；
- **错题本**：错题自动写入错题表，支持错题回顾与答案解析查看；
- **选项 JSON 存储**：选项以 JSON 字符串存储，一张试题表容纳所有题型，扩展新题型无需改表结构；
- **逻辑删除**：试卷表带逻辑删除字段，保留数据、查询过滤。

## 常见问题（FAQ）

**Q1：访问 404 / 页面空白？**
十有八九是没带 context-path。所有地址都要带 `/zaixianyuanchengkaoshixitong` 前缀。

**Q2：启动报数据库连接失败（Access denied）？**
application.yml 里数据库密码是默认值，先改成你本机 MySQL 密码；先用命令行验证账号能否登录，确认 MySQL 服务已启动。

**Q3：图片上传报错或不显示？**
上传图片存放在 `src/main/webapp/upload`，且**文件名不能含中文**——这是运行文档明确提醒的。

**Q4：多选题判分规则是什么？**
全对才得分。判分在后端完成，按正确答案逐题比对；单选/判断直接比对，填空比对标准答案。

**Q5：正确答案会不会泄露到前端？**
不会。判分在后端完成，答题页面不下发正确答案，这是考试系统的安全底线。

**Q6：Maven 依赖下载慢或工程报红？**
配置国内镜像源（如阿里云 Maven 镜像），删除本地仓库中下载不完整的目录后重新 update。

**Q7：管理员和老师功能重叠吗？**
老师端聚焦"题、卷、考"业务能力；管理员独有公告类型管理、老师管理、轮播图等全局配置能力，按职责切分权限。

**Q8：这个项目能用作毕业设计吗？**
可以作学习参考。基于通用脚手架风格二次开发，建议在其上做自己的业务改造，答辩时如实说明，能讲清原理比"从零手写"的说法更稳。

**Q9：有论文、PPT、任务书吗？**
本仓库（教学版）不含；完整版包含论文参考文档、演示 PPT、任务书、开题报告，仅供学习参考，论文请独立完成。

**Q10：有没有演示视频？**
没有。可先看完整版提供的运行截图（10 张）与论文截图（13 张），或按快速开始自行运行体验。
