### 一、视频简介（600-1000 字）

这期视频完整演示一套 SpringBoot 在线远程考试系统：管理员/老师/学生三种角色，从老师出题组卷、学生限时答题，到自动判分、错题回顾，全流程闭环。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 毕设、课程设计的同学参考。

【项目介绍】
技术栈：SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + MySQL，JDK 1.8；前端 Vue 2.6 + Element UI，前后端分离，后台管理端为打包好的 Vue 工程。标准 Maven 工程，接口统一封装，带自定义鉴权注解。基于通用脚手架风格二次开发，供学习交流用。

【完整功能清单】
前台 4 栏目：首页（核心内容与功能入口）、试卷列表（可参与的考试）、公告（考试通知）、个人中心（资料与成绩）。
后台功能：
- 学生端：个人中心、公告查看、考试管理（参与已发布考试）
- 老师端：个人中心、公告管理、用户管理（学生维护）、试卷管理、考试管理
- 管理员端：个人中心、公告类型管理、公告管理、用户管理、老师管理、试卷管理、考试管理、轮播图信息

【考试核心功能】
- 4 种题型：单选、多选、判断、填空（示例试题实测齐全）
- 试卷设考试时长（分钟）与总分数，答题计时
- 自动判分，成绩计入考试记录（带考试编号）
- 答题详情逐题留存，错题进错题表，支持错题回顾
- 试题带答案解析，选项 JSON 存储

【数据库说明】
库名 zaixianyuanchengkaoshixitong，脚本 db.sql 共 12 张表：业务表 7 张（试卷/试题/考试记录/答题详情/错题/公告/老师）+ 系统表 5 张（config/dictionary/token/users/yonghu），含 2 套示例试卷与 8 道示例试题，导入即用。账号：管理员 admin，用户 a1、老师 a1（密码 123456，管理员密码见说明文档）。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7+；Windows/macOS。启动：运行启动类或 mvn spring-boot:run。默认端口 8080，注意 context-path 是 /zaixianyuanchengkaoshixitong：前台 /zaixianyuanchengkaoshixitong/front/index.html，后台 /zaixianyuanchengkaoshixitong/admin/dist/index.html。上传图片文件名不能含中文（文档有说明）。
