### 正文（800-1200 字）

选题阶段最怕老师一句"这个系统业务太薄了"😅 管理类项目容易踩这个坑，但**在线考试系统**不会：出题、组卷、限时答题、自动判分、错题回顾，每一环都是实打实的功能，答辩演示全程有东西可看。今天把我实测跑通的一套 SpringBoot 在线远程考试系统完整拆给大家，功能、技术栈、数据库、材料一次讲完。

**为什么推荐这个方向**✅
1. 业务链路完整：出题 → 组卷（设时长总分）→ 限时答题 → 自动判分 → 成绩+错题本，一条线讲到底；
2. 技术点密度高：4 种题型、选项 JSON 存储、自动判分逻辑、三种角色权限，论文每章都有硬货；
3. 场景人人懂：谁都考过试，讲业务零解释成本。

**功能逐条列全**（三种角色，前后台完整）
前台 4 个栏目👇
✅ 首页：内容与功能入口
✅ 试卷列表：展示可参与的考试试卷
✅ 公告：考试通知、重要通知
✅ 个人中心：资料管理、查看考试成绩

后台功能分角色👇
学生端：个人中心、公告查看、考试管理（参与已发布考试）
老师端（5 组）：个人中心、公告管理、用户管理（学生维护）、试卷管理、考试管理
管理员端（8 组）：个人中心、公告类型管理、公告管理、用户管理、老师管理、试卷管理、考试管理、轮播图信息

**考试核心功能（这套的硬货）**👇
✅ 4 种题型：单选、多选、判断、填空（示例数据实测都有）
✅ 试卷可设考试时长与总分数，答题计时
✅ 答题后自动判分，成绩计入考试记录（带考试编号）
✅ 答题详情逐题留存，错题进错题表可回顾
✅ 试题带答案解析，选项 JSON 存储可扩展

**技术栈与版本**
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + MySQL，JDK 1.8；前端 Vue 2.6 + Element UI，前后端分离，后台管理端是打包好的 Vue 工程，开箱即用。学过 SSM 的上手很快。

**数据库**
库名 zaixianyuanchengkaoshixitong，脚本共 **12 张表**：业务表 7 张（试卷、试题、考试记录、答题详情、错题、公告、老师）+ 系统表 5 张（配置、字典、令牌、管理员、用户）。表结构层次分明，ER 图按"试卷-试题-记录-详情-错题"画，数据库设计章很好写。

**这套工程包含什么**
完整 Maven 工程、db.sql 脚本（12 张表+示例数据）、说明文档、运行必读、**论文参考文档（doc）**、**演示 PPT**、**任务书、开题报告**、论文截图 13 张、运行截图 10 张。
⚠️ 丑话说前面：**演示视频是没有的**，只能自己跑起来看；论文等文档仅供参考，请独立完成。

**运行门槛**
装 JDK 1.8 + Maven + MySQL（5.7+），建库导 db.sql，改 application.yml 密码，运行启动类就起来了。默认端口 8080，前台 /front/index.html，后台 /admin/dist/index.html。管理员 admin，用户/老师 a1（密码见说明文档）。
