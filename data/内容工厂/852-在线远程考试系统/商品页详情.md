**项目简介**

基于 SpringBoot 2.2.2 的在线远程考试系统：管理员/老师/用户（学生）三种角色，前台考试端 + 后台管理端，同一个 Maven 工程提供接口。基于通用脚手架风格二次开发，供学习交流使用。管理员账号 admin，用户 a1，老师 a1（密码见说明文档）。

**功能模块（分组逐条）**

前台（考试端，4 栏目）：
✅ 首页：核心内容与功能入口
✅ 试卷列表：展示可参与的考试试卷
✅ 公告：考试通知、重要通知
✅ 个人中心：资料管理、查看考试成绩

后台（学生端）：
✅ 个人中心：资料管理
✅ 公告管理：查看系统公告
✅ 考试管理：参与已发布的考试

后台（老师端，5 组）：
✅ 个人中心、公告管理
✅ 用户管理：学生用户维护
✅ 试卷管理：设置试卷名称、考试时长（分钟）、总分数、试卷状态
✅ 考试管理：考试发布与维护

后台（管理员端，8 组）：
✅ 个人中心
✅ 公告类型管理、公告管理
✅ 用户管理、老师管理
✅ 试卷管理、考试管理
✅ 轮播图信息管理

**考试核心功能（这套的硬货）**

✅ 4 种题型：单选、多选、判断、填空（示例数据实测齐全）
✅ 限时考试：试卷设考试时长，答题页计时
✅ 自动判分：后端逐题比对（多选全对才得分），成绩带考试编号入记录
✅ 错题本：错题自动入表，支持回顾与答案解析查看
✅ 答题详情：逐题答案留存，可回溯每次考试
✅ 设计亮点：选项 JSON 存储（一张试题表适配全部题型）、试卷逻辑删除

权限体系：Apache Shiro 实现三角色区分，token 登录态校验，接口层自定义注解鉴权；老师聚焦题卷考、管理员管全局，按职责切分。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；Thymeleaf；MySQL 5.7+；前端 Vue 2.6 + Element UI + axios（后台管理端已打包 dist）；工具库 fastjson/hutool/commons-lang3/commons-io。学过 SSM 的上手很快。
