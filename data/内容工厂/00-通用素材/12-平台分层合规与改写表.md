# 平台分层合规与改写表（v4 · 强制 · 取代 v3）

> v3 的错误：只盯"代做/包过"，却把**毕设、毕业设计、论文、答辩**当成安全词——用户实测这几类词在平台上一眼就是违规/敏感（尤其小红书、闲鱼、抖音、微博、知乎、B站）。
> v4 定调：**严格平台只介绍"单纯的项目信息"（这是什么项目、有什么功能、什么技术栈、怎么跑），完全不提学术场景**。

---

## 一、四层平台，四套写法

| 层 | 平台 | 处理方式 |
|---|---|---|
| **① 严格内容平台** | 小红书、抖音、微博、知乎、B站 | **只讲项目本身**：项目名/功能模块/技术栈/数据库/运行方式/演示。**禁止出现学术词**（毕设、毕业、毕业设计、论文、答辩、开题、课题、课程设计、学术）+ 交易词 + 导流词 + 极限词 |
| **② 交易平台（合规）** | 闲鱼 | 可以介绍交付内容与服务（工程/脚本/交付方式/演示），但**禁止学术词与学术不端词**；不写站外链接 |
| **③ 自建站（自由）** | 商城商品详情页 | **不做违规处理**——自己的站，可自由写（含学术场景、价格、服务、定制等），面向成交优化 |
| **④ 代码平台（含引流）** | Gitee、GitHub | **不做词语限制**（用户明确 GitHub 不用管），但**必须引流到自建站**：README 顶部放项目简介 + 演示/完整内容入口链接 |

---

## 二、严格平台（①）禁词清单（正文必须全部为 0）

**学术场景词**：毕设、毕业、毕业设计、毕业论文、论文、答辩、开题、开题报告、课题、课程设计、学术、毕设选题、毕业参考、毕设参考
**交易词**：源码（交易语境）、出售、价格、多少钱、下单、购买、优惠、免费送、付款、收款、交付（改用"包含"）
**导流词**：私信、主页（作为入口）、联系方式、微信、QQ、链接、站外、二维码
**学术不端/极限词**：代做、代写、包过、保毕业、最全、第一、唯一、永久、100%

**允许且鼓励**：项目名、系统、功能模块、前台/后台、技术栈、SpringBoot、MyBatis、Shiro、Thymeleaf、数据库、表、脚本、运行、端口、环境、演示、录屏、代码、工程、学习、交流、评论区、我踩过的坑、实测

## 三、严格平台的正确写法（示例）

### 标题（纯项目词，可被技术搜索命中）
- `SpringBoot 企业管理系统｜前后端完整 含数据库脚本`
- `Java 企业门户系统，后台权限+内容管理都做了`
- `企业管理系统 功能演示：前台5栏目+后台9模块`
- `SpringBoot 项目跑起来要几步？我整理了一遍`

### 正文结构（只讲项目）
1. 一句话：这是什么项目（技术栈 + 类型 + 完成度）
2. 功能模块逐条（前台 / 后台分开列，每条一句说明）
3. 技术栈与版本
4. 数据库（库名 + 表数量 + 分类）
5. 运行环境与步骤（JDK/Maven/MySQL/Redis、导脚本、改配置、启动命令、端口、访问路径）
6. 包含内容（工程、数据库脚本、运行说明、截图、演示录屏）
7. 适合谁用（做技术学习的、需要参考现成工程结构的、想了解权限/工作流实现的）
8. 常见技术问题（跑不起来怎么办 / 端口占用 / 数据库连不上）+ 我的排查思路
9. 评论区互动（合规 CTA，只做技术交流）

**全程不提"毕设/论文/答辩"**——让内容靠"项目关键词 + 技术价值"吸引人，转化在私域完成。

## 四、闲鱼（②）规则
- 标题：`企业管理系统 Java SpringBoot 完整工程 含数据库脚本 可运行`
- 允许：工程/代码/数据库脚本/包含内容/交付方式（网盘、在线发）/服务（远程协助、讲解）/演示录屏
- 禁止：毕设、毕业、论文、答辩、开题、代做、代写、包过、保毕业、最全、第一、永久
- 不写站外链接与联系方式

## 五、自建站商品页（③）
- **不做合规处理**，怎么有利于成交怎么写：可含"毕设/论文/答辩/价格/服务/定制/联系方式"
- 保留"卖点前置 + 功能分组 + 交付清单 + FAQ + 售后"结构

## 六、Gitee / GitHub（④）
- 不做词语限制（GitHub 尤其不用管）
- **必须引流到自建站**：README 结构 =
  1. 项目名 + 一句话简介
  2. `👉 完整项目 / 演示录屏 / 更多项目：{自建站地址}`（放在最显眼位置）
  3. 功能清单
  4. 技术栈
  5. 目录结构
  6. 快速开始（命令）
  7. FAQ
  8. 结尾再次引导：`更多完整项目 → {自建站地址}`

## 七、审核（机械可查）
- ① 严格平台 6 篇正文：**学术词、交易词、导流词、极限词全部为 0**
- ② 闲鱼：**学术词与学术不端词为 0**
- ③ 自建站商品页：不做检查
- ④ Gitee/GitHub：必须包含自建站链接（至少 2 处）
- 已删除：发布排期.md（用户确认不需要）
