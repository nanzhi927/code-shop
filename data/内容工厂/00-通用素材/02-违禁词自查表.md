# 02-违禁词自查表（v3 · 发布前必过）

> v3 变化：加入**平台分层**概念——A/B/C 三类平台各自的禁用词表不同；新增**品类违规黑名单**（"定制""源码出售""导流组合"等字面不违规但品类严打的写法）。依据：00-通用素材/12《平台分层合规与改写表（v3）》。
> 用法：每篇内容发布前，按文末"发布前 60 秒自查流程"扫一遍。任何禁用词命中 → 改写后再发。

## 一、平台分层禁词表（先定层级，再查词）

### A 类·内容平台（小红书/抖音/微博/知乎/B站）——最严，正文必须全部为 0

| 类别 | 禁用词（正文词频必须为 0） |
|---|---|
| 交易类 | 定制、代做、代写、包过、保毕业、源码出售、价格、下单、购买、优惠、免费送 |
| 导流类 | 私信、联系方式、微信、QQ、主页（作为导流入口时）、链接 |
| 极限词 | 最全、第一、唯一、永久 |

A 类补充规则：
- "毕设"只允许出现在**选题、答辩、学习语境**，不得与"源码/价格/交易"连用；
- "源码"避免交易语境（改用"工程/代码/项目"），标题不带"毕设源码"组合；
- CTA 只能是评论区互动（见 05 第一部分），不得有任何导流动作。

### B 类·交易平台（闲鱼/自建站商品页）——允许交易，禁以下词（正文必须为 0）

`代做`、`代写`、`包过`、`包答辩`、`保毕业`、`最全`、`第一`、`唯一`、`永久`、`破解`、`盗版`

B 类补充规则：
- 闲鱼不写站外链接、不提外部平台；
- "定制"若要提及，改为"二次开发/技术交流/按需改造"等合规说法；
- 主动写明"仅供学习参考，论文请独立完成"。

### C 类·代码平台（Gitee/GitHub）——技术文档风，禁以下词（正文必须为 0）

`代做`、`代写`、`包过`、`保毕业`、`出售`、`下单`、`价格`

C 类补充规则：全中文；保留运行步骤/结构树/FAQ/更新记录；注明"学习交流用，禁止商用"。

## 二、品类违规黑名单（字面不违规，但组合即违规——重点自查）

| 黑名单组合 | 为什么违规 | 合规做法 |
|---|---|---|
| "定制"高频出现（≥3 次/篇） | 指向"接单服务"，平台严打学术服务赛道 | A 类一律不用；改"技术答疑/思路交流/我踩过的坑" |
| "毕设"+"源码"连用（尤其标题） | 构成"源码交易"广告 | 解耦：标题用"企业管理系统毕设"或"完整工程"，不组合 |
| "私信/主页/联系方式"+微信 变体 | 导流动作，限流/删帖/封号 | 只做评论区互动；承接放账号主页资料（01 号文件） |
| "有需要私信我" | 变相交易引导 | 改"有同款问题的评论区留言，我看到都会回" |
| "帮你改题目/帮你加模块/帮你评估需求" | 承诺替人完成=服务承诺 | 改"这类问题的思路可以聊/评论区一起讨论" |
| "包更新/永久答疑" | 极限承诺 | 改"长期答疑/后续可咨询" |

## 三、通用禁用词（三类平台都禁）

1. **学术违规类**：代做、代写、包过、包答辩、保毕业、必过、稳过 → 学习参考、思路辅导、提前演练更安心
2. **绝对化/极限词**：最全、第一、唯一、永久、顶级、完美、100% 可运行、保证 → 已实测、亲测可跑、相对完整
3. **低价诱导类**：免费送、白嫖、秒杀、跳楼价 → 低价体验款（B 类正常标价；A 类不出现任何价格信息）
4. **版权风险类**：破解、破解版、盗版、搬运合集 → 学习版、教学示例、自测项目
5. **焦虑煽动类**：不做就毕不了业、再不买就没了 → 早准备更省心（不做虚假紧迫）
6. **他平台名**：各平台正文不点名其他平台（闲鱼、淘宝、B站、抖音等按所在平台规避）

## 四、发布前 60 秒自查流程

1. **定层级**（5 秒）：这篇发在 A/B/C 哪一类？确定用哪张禁词表。
2. **扫交易词**（15 秒）：全文搜"定制、代做、代写、价格、下单、购买、优惠、私信、微信、QQ、主页、链接"——A 类任一命中即打回；B/C 类按各自表核对。
3. **扫品类组合**（15 秒）：有没有"毕设+源码""定制+需求""私信+需要"这类黑名单组合？语境逐个确认。
4. **扫极限与承诺**（10 秒）：最全/第一/唯一/永久/100%/保证/包过 → 改"已实测/相对完整/长期答疑"。
5. **扫导流动作**（10 秒）：A 类正文与评论区是否只有"评论区互动"三级 CTA？有没有任何"找我去哪"的动作？承接只放账号主页资料。
6. **扫平台排他与来源声明**（5 秒）：没点名其他平台；B/C 类已写"仅供学习参考、论文独立完成"。

> 一票否决：A 类 21 词任一命中、B 类 11 词任一命中、C 类 7 词任一命中，必须改写后重查。
> 建议用脚本机械复查：对"发布区"文本逐词统计命中数（词频必须为 0），同时核对汉字数是否达到 11 号文件最小篇幅。
