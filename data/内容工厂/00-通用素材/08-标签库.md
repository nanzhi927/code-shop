# 08-标签库（各平台话题标签组合）

> 用法：项目文件只写"标签引用 00-通用素材/08"，发布时按平台从下表取组合。标签 = 主标签 + 技术栈标签 + 业务标签 + 长尾标签 + D 标签（引流标签）。

## 一、小红书（每篇 8-10 个）

**组合模板**：2 个 D 标签 + 2 个主标签 + 2 个技术栈标签 + 2 个业务标签 + 1-2 个长尾标签

**标签池**：
- D 标签（流量大）：#毕设 #毕业设计 #计算机毕业设计
- 主标签：#毕设源码 #毕设选题 #课程设计
- 技术栈：#Java毕设 #SpringBoot #Java #程序媛 #代码
- 业务（按项目替换）：#企业管理系统 #管理系统 #企业官网
- 长尾：#毕设怎么做 #毕设分享 #大学生日常 #计算机专业

**示例组合（企业门户项目）**：
#毕设 #计算机毕业设计 #毕设源码 #Java毕设 #SpringBoot #企业管理系统 #管理系统 #毕设怎么做 #计算机专业

## 二、B站（标签 + 分区）

- 分区：知识区 > 科学科普 / 计算机技术（按内容属性选）
- 标签池：毕业设计、毕设、Java、SpringBoot、源码、编程、程序员、管理系统（+业务词）、运行教程、课程设计
- 每视频选 5-8 个；标题已含业务词时标签侧重技术词 + "毕业设计""运行教程"

## 三、抖音（话题）

- 每条 3-5 个话题：#毕业设计 #毕设 #计算机 #Java（+业务词如 #管理系统）
- 热点话题轮换：#大学生 #程序员 #编程

## 四、知乎（话题绑定，答问时选）

- 主话题：毕业设计、计算机科学、Java、Spring Boot
- 辅助话题：编程学习、大学生活、软件工程
- 每答绑定 3-5 个与问题强相关的话题

## 五、微博（话题+超话）

- 每条 2-3 个：#计算机毕业设计# #毕设#（+业务词话题）
- 可加入相关超话发内容（校园类、程序员类超话）

## 六、Gitee / GitHub

- 用标签（topics）标注：`毕设` `毕业设计` `springboot` `管理系统`（+业务拼音/英文词如 `enterprise-portal` `java` `mybatis`）
- README 首行写中文项目名+（毕设学习版），便于站内搜索命中

## 七、闲鱼

- 标签即商品标题关键词（见 04-标题公式闲鱼模板），从 03-关键词库取词堆叠
- 每个商品 1 个低价锚点词（"可运行""含数据库"）+ 1 个用途词（"毕设""课程设计"）
