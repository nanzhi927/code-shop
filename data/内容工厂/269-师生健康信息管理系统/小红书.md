### 正文（800-1200 字）

选题被卡"场景太单薄"的同学看过来😭 我后来换了师生健康信息管理方向，一次过开题。因为这个题目天然有三种角色（管理员/教师/学生）、一条完整业务链（问卷→采集→返校统计），功能不用硬凑。今天把我跑通的一套 SpringBoot 师生健康信息管理系统完整拆开，功能、技术栈、数据库、踩过的坑一次讲完。

**为什么推荐这个选题**✅
业务一句话说清：校园场景下的健康信息收集与返校管理，答辩页面一放老师秒懂；三种角色天然对应权限设计，论文有技术点可写；工作量扎实但不失控，不会把自己绕进去。

**功能逐条列全**
这个系统一个入口登录，三种角色看到的菜单不一样👇

管理员 10 组功能：
✅ 学生管理：学号/姓名/性别/学院/专业/联系电话，增删改查
✅ 教师管理：工号/姓名/身份证/职称/联系电话
✅ 数据收集管理：住址、体温、身体状况等信息汇总
✅ 问卷分类管理 + 疫情问卷管理：问卷的新增/修改/删除
✅ 问卷调查管理：查看、修改、删除填报信息
✅ 返校信息管理：查看详情、下载、统计报表
✅ 数据采集管理 + 返校情况管理
✅ 个人中心

教师端：个人中心、疫情问卷（新增/在线作答）、问卷调查管理、数据采集查看、返校情况管理
学生端：个人中心、数据收集（填报体温/身体状况）、疫情问卷在线作答、返校信息管理

重点讲**业务链**：管理员发问卷 → 学生在线填 → 教师查看统计 → 返校信息汇总成报表。答辩按这条链演示，逻辑完整度直接拉满。

**技术栈与版本**
SpringBoot 2.2.2 + MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + Vue 2.6 + Element UI 2.13 + ECharts 4.6，JDK 1.8。前后端分离：后端出接口，前端是 Vue 管理端（工程里已带构建好的页面，不用装 Node 再编译）。学过 SSM 的上手很快。

**数据库**
库名 springboot43q56，一共 **12 张表**：3 张系统表（管理员/令牌/配置）+ 9 张业务表（教师、学生、疫情问卷、问卷调查、问卷分类、返校信息、返校情况、数据采集、信息采集）。表不多但每个角色都有对应表，ER 图按"角色-业务链"画，很好讲。

**这套工程包含什么**
完整 Maven 工程（含前端）、db.sql 数据库脚本（12 张表+示例数据）、说明文档、运行必读、运行截图 8 张，还**自带论文参考文档和 PPT 素材**——文档是学习参考用的，自己的论文还是要自己写✍️
⚠️ 丑话说前面：环境（JDK/MySQL）要自己装，工程里没有录屏演示视频。

**运行门槛**
装 JDK 1.8 + MySQL，建库导入 db.sql，改 application.yml 里的数据库密码，IDEA 里跑主类（或 mvn spring-boot:run）。端口 8080，浏览器开 `localhost:8080/springboot43q56/admin/dist/index.html` 就进系统了，管理员账号 abo。

**我踩过的坑**
1. 访问地址别漏了中间的 /springboot43q56 路径，直接开 8080 会 404；
2. 数据库密码默认写的 123456，装库时密码不同一定要改配置，这是跑不起来的头号原因；
3. 先跑通再动笔，别文档写完发现环境起不来，返工最痛。
