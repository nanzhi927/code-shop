**项目简介**

基于 SpringBoot 2.2.2 的师生健康信息管理系统：前后端分离架构，后端提供 REST 接口，前端为 Vue 2.6 + Element UI 2.13 管理端（工程内已含构建产物，运行无需 Node 环境）。三种角色同一入口登录，按角色加载不同菜单。

**功能模块（分组逐条）**

管理员端（10 组功能）：
✅ 学生管理：学号/姓名/性别/学院/专业/联系方式，增删改查
✅ 教师管理：工号/姓名/身份证/职称/联系方式，增删改查
✅ 数据收集管理：住址、体温、身体状况等填报信息汇总
✅ 问卷分类管理：问卷分类维护
✅ 疫情问卷管理：问卷新增、查看详情、修改、删除
✅ 问卷调查管理：填报信息的查看、修改、删除
✅ 返校信息管理：查看详情、下载、统计报表
✅ 数据采集管理：采集信息查看详情、修改、删除
✅ 返校情况管理：返校状态查看与维护
✅ 个人中心：个人信息查看编辑

教师端（5 组）：个人中心、疫情问卷（新增/在线作答）、问卷调查管理、数据采集查看、返校情况管理。
学生端（4 组）：个人中心、数据收集填报（住址/体温/身体状况）、疫情问卷在线作答、返校信息管理。

核心业务链：管理员发布问卷 → 学生在线作答 + 填报健康数据 → 教师查看汇总 → 管理员生成返校统计报表。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；FastJson 1.2.8；Hutool 4.0.12；前端 Vue 2.6 + Element UI 2.13 + ECharts 4.6 + axios；数据库 MySQL 5.7/8.0。学过 SSM 的上手很快。

**数据库说明**

库名 springboot43q56，共 12 张表：系统表 3 张（users 管理员 / token 登录令牌 / config 全局配置）、业务表 9 张（jiaoshi 教师 / xuesheng 学生 / yiqingwenjuan 疫情问卷 / wenjuandiaocha 问卷调查 / wenjuanfenlei 问卷分类 / fanxiaoxinxi 返校信息 / fanxiaoqingkuang 返校情况 / shujucaiji 数据采集 / xinxicaiji 信息采集）。脚本含建库语句与示例数据，导入即用，ER 图、表结构素材管够。

**运行环境**

JDK 1.8+、MySQL 5.7/8.0；Windows/macOS 均可。启动流程：建库（utf8）→ 导入 db.sql → 改 application.yml 数据库密码 → IDEA 运行主类（或 `mvn spring-boot:run`）。浏览器（推荐 Chrome）访问 `http://localhost:8080/springboot43q56/admin/dist/index.html`。管理员账号 abo（密码见运行必读）。
