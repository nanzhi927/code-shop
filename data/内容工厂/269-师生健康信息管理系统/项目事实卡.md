# 项目事实卡：269 师生健康信息管理系统

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13）。

## 一、技术栈与版本
- Java 1.8；SpringBoot 2.2.2.RELEASE（pom.xml parent）；MyBatis-Plus 2.3（mybatis-spring-boot-starter 2.1.1）；Apache Shiro 1.3.2；FastJson 1.2.8；Hutool 4.0.12；commons-lang3 / commons-io；pom 中另含百度 AI java-sdk 4.4.1 与 SQLServer 驱动（未在业务代码中确认实际使用，不对外宣传相关功能）
- 前端：Vue 2.6.10 + Element UI 2.13.0 + axios + ECharts 4.6 + vue-router 3.1.5 + vue-quill-editor（管理端为 Vue CLI 工程，**工程内已含构建好的 dist 产物**，运行无需 npm 构建）

## 二、功能模块（依据 运行必读.txt + Controller/views 目录核实）
- **三种角色**：管理员、教师、学生，同一管理端入口登录，按角色展示不同菜单（工程内未包含独立前台站点，运行必读中前台地址留空——如实说明）
- **管理员**：个人中心；学生管理（学号/姓名/性别/学院/专业/联系方式）；教师管理（工号/姓名/身份证/职称/联系方式）；数据收集管理（住址/体温/身体状况）；问卷分类管理；疫情问卷管理（新增/查看/修改/删除）；问卷调查管理（查看/修改/删除填报信息）；返校信息管理（查看详情/下载/统计报表）；数据采集管理；返校情况管理
- **学生**：个人中心；数据收集（填报考勤位置/体温/身体状况）；疫情问卷（查看/在线作答/搜索）；返校信息（查看/添加/修改/删除）
- **教师**：个人中心；疫情问卷（新增/在线作答）；问卷调查管理；数据采集查看；返校情况管理

- 数据库：MySQL（jdbc:mysql://127.0.0.1:3306/springboot43q56），默认账号 root / 123456（application.yml，需改成自己的）
- 启动：IDEA 导入 Maven 工程后运行 `SpringbootSchemaApplication`，或 `mvn spring-boot:run`
- 访问：`http://localhost:8080/springboot43q56/admin/dist/index.html`（说明文档.txt 指定，推荐谷歌浏览器）
- 环境：JDK 1.8+，MySQL 5.7/8.0，Windows/macOS；无需 Node 环境（前端为已构建 dist）
