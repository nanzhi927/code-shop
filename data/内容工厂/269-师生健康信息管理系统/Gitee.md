# 师生健康信息管理系统-SpringBoot（毕设学习版）

基于 SpringBoot 的师生健康信息管理系统**教学版**：管理员、教师、学生三种角色同一入口登录、按角色显示菜单，覆盖"问卷发布→在线填报→数据采集→返校统计"完整业务链，前后端分离架构，数据库 12 张表导入即用，适合毕业设计、课程设计的学习参考与技术交流。

> 本仓库为教学版，供学习交流使用；完整版（含全部资料与运行说明）获取方式见文末引导。

## 项目简介

- **架构**：前后端分离——后端 SpringBoot 2.2.2 提供 REST 接口，前端 Vue 2.6 + Element UI 2.13 管理端（工程内已含构建产物，运行无需 Node 环境）。
- **角色**：管理员 / 教师 / 学生，同一登录入口，登录后按角色加载不同菜单（Apache Shiro 1.3.2 + token 机制）。
- **数据库**：MySQL，库名 `springboot43q56`，12 张表（系统表 3 张 + 业务表 9 张），脚本自带建库语句与示例数据，导入即用。
- **工程**：标准 Maven 结构，JDK 1.8。

## 快速开始

第 1 步：导入数据库

```sql
create database springboot43q56 default character set utf8;
use springboot43q56;
source 你的路径/db.sql;
```

或命令行直接导入：

```bash
mysql -u用户名 -p springboot43q56 < db.sql
```

导入后应能看到 12 张表；表数量不足说明脚本未导完，重新导入即可。

第 2 步：修改配置。打开 `src/main/resources/application.yml`：
- 数据库连接：用户名、密码改成你自己的（默认 root / 123456）；
- 端口：默认 8080，被占用可修改 `server.port`；
- 上下文路径 `/springboot43q56` 保持默认即可。

第 3 步：启动

```bash
mvn spring-boot:run
```

或在 IDEA 中导入 Maven 工程后运行启动类 `SpringbootSchemaApplication`。

第 4 步：访问验证
- 管理端：`http://localhost:8080/springboot43q56/admin/dist/index.html`（推荐 Chrome；账号信息见完整版运行说明）
- 注意地址中间的 `/springboot43q56` 上下文路径不要遗漏，直接访问 8080 会 404

看到启动完成日志即运行成功。

## 常见问题（FAQ）

**Q1：启动报数据库连接失败（Access denied / Communications link failure）？**
九成是 application.yml 里数据库密码/用户名没改对，或 MySQL 服务未启动。先在命令行用同样账号密码登录 MySQL 验证。

**Q2：打开 localhost:8080 是 404？**
漏了上下文路径，完整地址是 `localhost:8080/springboot43q56/admin/dist/index.html`。

**Q3：报端口被占用（Port 8080 was already in use）？**
把 `server.port` 改成 8081 等未占用端口，或找到占用进程处理。

**Q4：需要安装 Node.js 吗？**
不需要。前端构建产物已包含在工程里（admin/dist），运行只需 JDK + MySQL。

**Q5：三种角色怎么登录？**
同一登录入口，按角色输入对应账号；管理员账号在 users 表，教师、学生账号在对应业务表，可登录管理端维护。账号信息见完整版运行说明。

**Q6：前端想二次开发怎么办？**
工程包含前端 Vue 源码（admin/admin/src），可自行 `npm install && npm run serve` 调试，改完重新构建替换 dist。

**Q7：这个项目能用作毕业设计吗？**
可以作学习参考。代码为代码生成器风格脚手架二次开发，建议在其上做自己的业务定制，答辩时如实说明，能讲清原理比"从零手写"的说法更稳。

**Q8：有论文或开题报告吗？**
工程资料含论文参考文档与 PPT 素材，仅供学习参考；开题报告未包含。论文请自己撰写，技术实现思路可以交流。

**Q9：支持哪些系统？MySQL 8 可以吗？**
Windows / macOS 均可；MySQL 5.7 / 8.0 都支持。

**Q10：12 张表是不是太少了？**
表不在多在于落点：3 张系统表 + 9 张业务表，覆盖三个角色和问卷、采集、返校三个业务域，ER 图清晰好讲；需要扩展业务时按同样模式加表即可。
