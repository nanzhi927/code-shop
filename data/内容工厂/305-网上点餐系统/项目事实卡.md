# 项目事实卡：305 网上点餐系统

> 事实以本卡为准，所有平台文案不得偏离。已对照源码逐项核实（核实日期 2026-09-13，源码目录 `D:\从戎网站源码\springboot源码\1\网上点餐系统`）。

## 一、技术栈与版本（读 `springboott01gx/pom.xml`）

- 语言/编译：Java 1.8（`<java.version>1.8</java.version>`）
- 框架：SpringBoot **2.2.2.RELEASE**（`spring-boot-starter-parent` 版本）
- ORM：MyBatis（`mybatis-spring-boot-starter` **2.1.1**）+ MyBatis-Plus **2.3**（`mybatisplus-spring-boot-starter` **1.0.5**）；`spring-boot-starter-jdbc`
- 权限/安全：Apache Shiro **1.3.2**（`shiro-spring`）+ 自研 `AuthorizationInterceptor` 令牌拦截
- 数据库驱动：`mysql-connector-java`（版本由 SpringBoot 父 POM 管理）
- 其他依赖：FastJSON **1.2.8**、Hutool **4.0.12**、commons-lang3 **3.0**、commons-io **2.5**、protobuf-java **3.10.0**、validation-api **2.0.1.Final**、Baidu AI `java-sdk` **4.4.1**（工程内 `BaiduUtil`/`AipFace` 工具类，具体启用功能未逐项确认）、SQLServer 驱动（备用，配置已注释）
- 前端：前台为 Vue2 + layui + jQuery + bootstrap CSS + ElementUI 资源（`resources/front/front/`）；后台管理端为 Vue 打包产物（`resources/admin/admin/dist/`）
- 构建：Maven（`spring-boot-maven-plugin`）；工程内另有 `pom-war.xml`、`mvnw`/`mvnw.cmd`

## 二、功能模块（读 Controller + 前端 pages + 说明文档）

- **三种角色**：用户、美食店、管理员
- **前台 6 栏目**（`resources/front/front/pages/`）：首页（轮播图）、美食店、美食信息、美食评价、美食资讯、个人中心；另有用户注册/登录、后台管理入口
- **用户功能**：首页；个人信息修改（账号/姓名/性别/年龄/头像/手机/配送地址）；美食订单管理；美食评价管理；我的收藏管理；对美食信息可**点餐**（生成订单）、**收藏**
- **美食店功能**：首页；店铺信息修改；美食信息管理；美食订单管理；美食评价管理
- **管理员功能（后台）**：用户管理、美食店管理、美食分类管理、美食信息管理、美食订单管理、美食评价管理、美食资讯、轮播图管理（系统管理）、个人中心
- 后端 Controller：`CommonController`（通用查询/地图定位）、`ConfigController`（配置与轮播图）、`FileController`（文件上传）、`MeishidianController`、`MeishidingdanController`、`MeishifenleiController`、`MeishipingjiaController`、`MeishixinxiController`、`NewsController`、`StoreupController`、`UserController`、`YonghuController`
