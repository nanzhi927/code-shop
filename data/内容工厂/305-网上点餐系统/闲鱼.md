### 商品描述（600-1000 字）

【项目定位】
一套三端角色的 SpringBoot 网上点餐系统：用户点餐端 + 美食店商家端 + 管理员后台，一个 Maven 工程跑通。本机实测跑通才上架，运行截图齐全，可以先看截图再决定拍不拍。

【功能清单·前台 6 栏目】
✅ 首页：轮播大图（后台可配）+ 栏目导航
✅ 美食店：店铺列表 + 详情（名称、照片、电话、介绍、地址、招牌美食、联系人）
✅ 美食信息：列表 + 详情（名称、分类、所属店铺、口味、特色、单价、图文详情），支持点餐、收藏
✅ 美食评价：评价列表 + 详情（评分、内容、评价时间）
✅ 美食资讯：文章列表 + 详情，后台发文即更新
✅ 个人中心：个人信息、美食订单管理、美食评价管理、我的收藏管理

【功能清单·三种角色】
✅ 用户端：注册登录、维护个人资料、点餐提交订单、查看订单状态、写评价、收藏
✅ 美食店端：维护本店美食信息、处理本店订单、回复评价、维护店铺资料
✅ 管理员后台：用户管理、美食店管理、美食分类管理、美食信息管理、订单管理、评价管理、美食资讯、轮播图管理

后台改美食、换轮播图，前台刷新即生效，不用改代码。

【技术栈】
Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis + MyBatis-Plus 2.3；Apache Shiro 1.3.2（登录鉴权 + 令牌拦截）；FastJSON、Hutool 等；前端 Vue + layui + ElementUI 风格。标准 Maven 工程，基于现成脚手架工程二次开发，供学习交流用。

【数据库】
MySQL，库名 springboott01gx，脚本共 **11 张表**：系统类 3 张（管理员、登录令牌、配置）+ 业务类 8 张（用户、美食店、分类、美食信息、订单、评价、资讯、收藏），含建库语句与示例数据，导入即用。订单表含订单编号、单价、点餐数量、总金额、配送地址、提交时间、是否审核、是否支付等字段。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7/8.0；Windows / macOS 均可。流程：导入 db.sql（脚本自动建库）→ 改 application.yml 数据库密码 → `mvn spring-boot:run`。端口 **8080**，访问路径带上下文 `/springboott01gx`（前台 front、后台 admin/dist 两个入口）。
