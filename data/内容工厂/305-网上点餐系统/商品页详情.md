**项目简介**

基于 SpringBoot 2.2.2 的网上点餐系统完整前后端工程，三种角色（用户 / 美食店 / 管理员）在同一个 Maven 工程内按权限区分菜单与数据范围。基于现成脚手架工程二次开发，供学习交流使用。管理员账号见说明文档（abo）。**本商品仅供学习参考，论文请独立完成。**

**功能模块（分组逐条）**

前台（点餐端，6 栏目）：
✅ 首页：轮播大图 + 栏目导航，轮播图后台可配
✅ 美食店：店铺列表 + 详情（名称、照片、电话、介绍、地址、招牌美食、联系人）
✅ 美食信息：列表 + 详情（美食名称、分类、所属店铺、电话、图片、口味、特色、单价、图文详情），支持点餐与收藏
✅ 美食评价：评价列表 + 详情（店铺、美食、用户、评分、评价内容、图片、评价时间）
✅ 美食资讯：资讯列表 + 详情，后台发文即更新
✅ 个人中心：个人信息、美食订单管理、美食评价管理、我的收藏管理

用户端：
✅ 注册登录、个人资料维护（账号、姓名、性别、年龄、头像、手机、配送地址）
✅ 点餐提交订单、查看订单状态、写评价、管理收藏

美食店商家端：
✅ 维护本店美食信息（新增 / 修改 / 删除）
✅ 处理本店订单、查看与回复顾客评价
✅ 维护店铺资料（名称、照片、电话、介绍、地址、招牌美食、联系人）

管理员后台（9 组）：
✅ 用户管理、美食店管理、美食分类管理
✅ 美食信息管理、美食订单管理、美食评价管理
✅ 美食资讯发布、首页轮播图管理
✅ 个人中心（后台账号维护）

权限体系：Apache Shiro 1.3.2 完成登录鉴权，配合令牌拦截器按角色过滤数据范围——用户只见自己的订单，美食店只管本店数据，管理员看全量。答辩讲权限时，切两个账号现场演示最直观。

**技术架构与版本**

Java 1.8；SpringBoot 2.2.2.RELEASE；MyBatis（mybatis-spring-boot-starter 2.1.1）+ MyBatis-Plus 2.3；Apache Shiro 1.3.2；FastJSON 1.2.8、Hutool 4.0.12、commons-lang3 3.0、commons-io 2.5 等工具库；数据库驱动 mysql-connector-java；前端 Vue + layui + jQuery + ElementUI 风格资源；构建 Maven（另含 pom-war.xml 备用）。学过 SSM 或 SpringBoot 的上手很快。

**数据库说明**

MySQL，库名 `springboott01gx`，共 **11 张表**：系统类 3 张——管理员表（users）、登录令牌表（token）、配置表（config，首页轮播图存这里）；业务类 8 张——用户（yonghu）、美食店（meishidian）、美食分类（meishifenlei）、美食信息（meishixinxi）、美食订单（meishidingdan）、美食评价（meishipingjia）、美食资讯（news）、收藏（storeup）。脚本含 `CREATE DATABASE`、建表语句与示例数据，可重复执行（先 DROP 再 CREATE）。

订单表字段最值得说：订单编号、美食名称、店铺账号与名称、联系电话、`jiage` 单价、`goumaishuliang` 点餐数量、`zongjiage` 总金额、用户账号/姓名/手机、配送地址、提交时间、`sfsh` 是否审核（默认否）、`shhf` 审核回复、`ispay` 是否支付（默认未支付）。ER 图按"角色层 / 业务主链 / 辅助表"三层画最省事。

**运行环境**

JDK 1.8+、Maven、MySQL 5.7 / 8.0；Windows / macOS 均可。启动流程：导入 db.sql（脚本自动建库）→ 修改 `src/main/resources/application.yml` 的数据库用户名与密码 → `mvn spring-boot:run`（或 `mvn clean package -DskipTests` 后 `java -jar target/springboott01gx-0.0.1-SNAPSHOT.jar`）。端口 **8080**，访问路径必须带上下文 `/springboott01gx`：前台 `/springboott01gx/front/index.html`，后台 `/springboott01gx/admin/dist/index.html`。管理员账号见说明文档。
