### 一、视频简介（600-1000 字）

这期完整演示一套 SpringBoot 网上点餐系统：用户点餐端、美食店商家端、管理员后台三端都做了，一个工程里跑通。我本机实测跑通才录的这期，从功能演示到运行教程一次讲完，适合做 Java 方向订单类题目的同学参考。

【项目介绍】
技术栈：Java 1.8 + SpringBoot 2.2.2.RELEASE + MyBatis / MyBatis-Plus 2.3 + Apache Shiro 1.3.2 + FastJSON / Hutool；前端是 Vue + layui + ElementUI 风格页面；标准 Maven 工程，数据库 MySQL 5.7 / 8.0。

【完整功能清单】
三种角色：用户、美食店、管理员。
- 前台 6 栏目：首页（轮播图后台可配）、美食店、美食信息、美食评价、美食资讯、个人中心。
- 用户端：注册登录、个人信息维护、点餐提交订单、查看订单状态、写评价、收藏美食。
- 美食店端：维护本店美食信息、处理本店订单、查看与回复评价、维护店铺资料。
- 管理员后台：用户管理、美食店管理、美食分类管理、美食信息管理、美食订单管理、美食评价管理、美食资讯、轮播图管理、个人中心。

【数据库说明】
库名 springboott01gx，脚本共 **11 张表**：系统类 3 张（管理员、登录令牌、配置/轮播图）+ 业务类 8 张（用户、美食店、美食分类、美食信息、美食订单、美食评价、美食资讯、收藏），含建库语句与示例数据，导入即用。订单表字段覆盖订单编号、美食、店铺、单价、点餐数量、总金额、配送地址、提交时间、是否审核、审核回复、是否支付。

【运行环境】
JDK 1.8+、Maven、MySQL 5.7 / 8.0；Windows / macOS 均可。启动：`mvn spring-boot:run`，或 `mvn clean package -DskipTests` 后 `java -jar target/springboott01gx-0.0.1-SNAPSHOT.jar`。端口 **8080**，**访问路径带上下文 `/springboott01gx`**：前台 `/springboott01gx/front/index.html`，后台 `/springboott01gx/admin/dist/index.html`，管理员账号见说明文档。

**【1:30-2:40 用户端闭环】**（画面：美食详情 → 点餐提交 → 个人中心订单列表 → 写评价）

**【2:40-3:40 商家端】**（画面：商家账号登录 → 美食信息管理 → 订单管理 → 评价管理）
"换美食店账号登录。这里只能看到本店的数据：美食信息管理，能新增修改删除自己的菜品；美食订单管理，处理本店收到的订单；美食评价管理，看顾客对本店的评价。这个'只看自己数据'的设计，就是三端权限最直观的演示——答辩被问权限，切两个账号给老师看，比解释半天有用。"

**【3:40-4:40 管理员后台】**（画面：后台登录 → 用户管理 → 美食店管理 → 美食分类管理 → 轮播图管理）

**【4:40-5:20 数据流与评价】**（画面：后台改一条美食 → 前台刷新出现）
"把数据流串一下：美食分类挂美食信息，美食信息挂店铺，用户对着美食点餐生成订单，订单处理完产生评价，评价又汇总回店铺和美食。这条链子画成图，就是论文系统设计那章的核心插图。"
